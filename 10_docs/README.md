# Cotaska 文書目次

このフォルダは、現行仕様を示す設計書と、その成立経緯を示す履歴資料を分けて管理する。

| 区分 | 目的 | 起点 |
| --- | --- | --- |
| `10_運用ルール` | 開発・変更・不具合・リリースの運用ルール | [運用ルール](10_運用ルール/) |
| `20_設計` | 現在の動作を示す正本 | [設計目次](20_設計/README.md) |
| `30_変更管理` | 仕様変更、不具合、DB、リリースの履歴 | [変更管理目次](30_変更管理/README.md) |

新規参加者は、まず `20_設計/README.md` から対象機能の正本を確認し、変更理由や発生事象が必要な場合に `30_変更管理` を参照する。
