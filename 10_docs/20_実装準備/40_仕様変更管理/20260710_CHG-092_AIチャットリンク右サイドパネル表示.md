# CHG-092 AIチャットリンク右サイドパネル表示

## 変更ID

CHG-092

## 変更内容

AIチャット上の Markdown リンクをクリックしたとき、ローカルファイルは外部アプリではなくAIチャット右サイドパネルで開く。タスクファイルはタスク詳細、テキストファイルはテキストプレビュー、Markdown はプレビュー/テキスト表示、PDF はPDFプレビューを既存の添付ファイルクリック時と同じ導線で表示する。

## 変更理由

T-0385 / BUG-20260710-02 では白画面化を防ぐため外部アプリ起動とアプリ外遷移ガードを対策としていたが、利用者の期待動作は添付ファイルクリック時と同じく Cotaska 内の右サイドパネルで内容を確認できることだったため。

## 影響範囲

- UI: AIチャットの Markdown リンククリック挙動
- IPC: リンク先を安全に解決して renderer に返す処理
- 既存機能: 添付ファイルクリック時の右サイドパネル表示、タスク詳細表示、テキスト/PDFプレビュー
- セキュリティ: メインウィンドウの外部URL/ローカルファイルへの直接遷移ガードは維持する

## 設計反映先

- `10_docs/10_設計/20_基本設計/06_AI連携.md`

## 完了条件

- AIチャット本文または右サイドパネル内Markdownプレビューのローカルファイルリンクをクリックすると、Cotaska のメイン画面が白画面にならない。
- `T-XXXX.md` 形式のタスクファイルリンクは右サイドパネルにタスク詳細として表示される。
- テキスト/Markdown/PDFリンクは添付ファイルクリック時と同じ右サイドパネル表示になる。
- `http://` / `https://` は従来どおり既定ブラウザで開く。
- `file://`、相対パス、URLエンコード、行番号付きリンクを扱える。

## テスト観点

- AIチャット回答内のローカルMarkdownリンク
- AIチャット回答内の `file://...md:1` リンク
- 右サイドパネル内Markdownプレビューからの相対リンク
- タスクファイル、通常テキスト、Markdown、PDF、存在しないファイル
- 外部URLクリック時の既定ブラウザ起動

## 設計・実装結果

- `AiChatPane` は Markdown リンクを直接遷移させず、`aiChat:resolveLinkTarget` で解決したローカルファイルを既存 `openFileContext` へ渡す。
- `file://`、相対パス、URLエンコード、`path:line[:column]` の行番号サフィックスを main process で正規化する。
- 右プレビュー内の Markdown 相対リンクは、プレビュー中ファイルの親ディレクトリを基準に解決する。AIチャット本文の相対リンクは設定済み作業フォルダを基準に解決する。
- `http://` / `https://` は既定ブラウザを維持し、存在しないファイル・フォルダ・未対応リンクは右プレビューのエラーとして表示する。メインウィンドウの遷移ガードは変更しない。
