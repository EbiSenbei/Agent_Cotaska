| --- | --- | --- |
| [10_技術資料](10_技術資料/) | [実装技術の選定](10_技術資料/実装技術の選定.md) | 技術スタックと技術選定の正本 |
| [20_デザイン素材/10_ロゴ案](20_デザイン素材/10_ロゴ案/) | ロゴ案・確定ロゴ画像 | デザイン検討・参照用素材 |

デザイン素材は履歴を失わないよう削除せず、用途別に分けて管理する。採用済み素材をアプリ配布物へ反映する場合は、アプリ側の参照先とリリース手順も更新する。
