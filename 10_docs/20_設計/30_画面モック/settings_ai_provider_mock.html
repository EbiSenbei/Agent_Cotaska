AI共通

AI連携（共通設定）

連携先の選択と、Codex / ClaudeCode で共用する設定。

連携先
AIチャットで使う連携先。選択に応じて下の「Codex関連」「ClaudeCode関連」を切り替えます。
作業フォルダ
AIモードのファイルツリー表示とAI実行時の作業フォルダ。プロジェクトフォルダ外も指定できます。両プロバイダ共通。
AI参照上限
ファイル 件
合計 文字
添付した参照ファイルの内容をAIへ送る方法と上限。初期値は10件、100,000文字。
AI診断ログ
通常はOFF。ONにするとAI応答時間、トークン数などをアプリログへ出力します。
AIデータ削除
保持 日
指定日数以前のアーカイブ済みAIスレッドと関連履歴を削除します。タスク本体は削除しません。
AI-Codex関連

Codex（OpenAI）設定

連携先が Codex のときに使う設定。

Codexモデル
AIチャットの標準モデル。チャット入力欄でも送信前に一時変更できます。
権限
Codex SDK実行時の既定権限（sandboxMode）。
AI速度
速度優先ではFast mode設定と短命Codex実行を使います。
Codex認証状態

AI-ClaudeCode関連

Claude Code（Anthropic）設定

連携先が Claude Code のときに使う設定。

⚠ ローカルサブスク認証は個人利用限定です。配布ビルドではこのモードは選択できません（クラウドプロバイダ(Bedrock)のみ）。
認証方式
ローカル: `~/.claude/` のログインを利用（配布不可）。Bedrock: AWS資格情報で利用（配布可・従量課金）。
Claudeモデル
AIチャットで使う Claude モデル。
権限
Claude 実行時の権限（permissionMode）。sandboxMode から変換した表記。
AI速度
Claude 側の応答プロファイル。
Bedrockリージョン*
例: ap-northeast-1 / us-east-1。認証方式がクラウドプロバイダ（Amazon Bedrock）の場合は必須です。
Bedrockリージョンは必須です。
BedrockモデルID*
認証方式がクラウドプロバイダ（Amazon Bedrock）の場合は必須です。
BedrockモデルIDは必須です。
AWS資格情報*
AWSプロファイル名または資格情報。平文保存はせず、OS資格情報ストア（safeStorage）等で保管します。認証方式がクラウドプロバイダ（Amazon Bedrock）の場合は必須です。
AWS資格情報は必須です。
