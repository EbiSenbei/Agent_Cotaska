# タスク添付ファイル（CHG-140）

## Markdown画像とクリップボード（CHG-141）

詳細ペインと独立詳細ウィンドウの共通DetailPaneで実装する。画像を含むpasteイベントのみ通常貼り付けを止め、Mainのclipboard.readImageからPNGを取得する。attachments.pasteImage(taskId)は20MB以下の画像をattachments/image-時刻.pngへ排他保存し、同名は連番で回避する。旧形式タスクは既存のensureTaskFolderで個別移動する。全ウィンドウへ添付変更を通知する。

保存成功後に選択範囲を![Image](<attachments/ファイル名>)で置換する。保存中は本文編集と重複貼り付けを止める。保存失敗時は参照を挿入せずエラーを表示する。保存中に画面を離れた場合は本文挿入を行わず、保存画像は添付として保持する。通常テキスト貼り付けはブラウザ標準動作を維持する。

attachments.readImage(taskId, reference)は本文のフォルダを基準に相対画像を解決し、data URLを返す。日本語・空白・URLエンコードを扱う。タスク外への遡上、絶対パス、リンク、20MB超、非画像を拒否する。PNG/JPEG/GIF/WebP/BMP/SVG/ICO/AVIFに対応。HTTP(S)画像は通常のimg表示。画像はペイン幅以下・縦横比維持とし、欠損や読込失敗は代替テキストと理由を表示する。取り外し・復元の変更通知で再読込する。複製・バックアップは既存のタスク添付一式保存に含める。

## 保存

新規本文はtasks/T-ID/T-ID.md、添付は同階層のattachments/にコピー保存する。添付は本文からattachments/ファイル名で参照可能。旧形式本文は読み込み・更新・バックアップ復元を維持し、添付追加時にそのタスクだけIDフォルダへ移動する。一括移行は専用スキルに分離する。

添付フォルダは初回追加時に作成する。タスク探索と監視はattachments配下を除外する。UIは本文とは別に一覧と追加・開く・取り外し・復元を提供する。取り外した添付はattachments/.removed/の一意フォルダへ移し、同名があれば別名で復元する。上書き・実ファイルの永久削除を行わない。

## API

cotaskaAPI.attachmentsのlist(taskId)、add(taskId)、open(taskId, name)、remove(taskId, name)、restore(taskId, token)を提供。追加元はMainのファイル選択ダイアログで決定する。Rendererから任意の保存先パスを受け取らない。タスクIDはキャッシュから解決し、パス成分・シンボリックリンクを拒否する。変更後は全タスクウィンドウへattachments:changedを通知する。

## ライフサイクル

ゴミ箱では添付を保持する。タスク複製は添付（取り外し済みを含む）もコピーし、本文の相対リンクが維持される。アーカイブはarchive/T-ID/T-ID.mdとattachments.zip、その他のタスク内資料を保管する。既存の同名アーカイブは上書きせず停止する。

アーカイブ処理は一時保存先にタスクフォルダ全体をコピーしてから添付をZIP化し、各エントリのバイト内容を検証する。検証後に一時保存先の添付フォルダを除去し、正式アーカイブへ移す。元タスクの削除は最後に行い、圧縮・保存失敗時は元を保持する。本文は平文で検索可能。ZIP内の添付はOSのZIP閲覧で確認できる。

## バックアップと移行

既存のtasks/archive再帰バックアップに添付・取り外し済み資料・ZIPを含める。インデックスは保存せず復元後に生成。旧形式を自動一括移行しない。同期中のプロジェクトは全PCのアプリ・同期を停止し、対応版を揃えてから専用スキルで一か所だけ移行する。

大容量資料では現在の同期ZIP処理に時間・メモリが必要。圧縮済み画像・動画等の容量削減は保証しない。バックアップ先をtasks/archive配下に置くことを拒否し、バックアップ自身の混入を避ける。
