## 現象

検索画面で検索結果のタスクを選択し、右側のタスク詳細から内容を変更しても、検索結果一覧側の表示が更新されない。

## 再現手順

1. 左サイドバーの検索を開く。
2. 任意のキーワードでタスクを検索する。
3. 検索結果からタスクを選択する。
4. タスク詳細でタイトル、本文、期限、タグ、完了状態などを変更する。

## 期待動作

タスク詳細で保存された内容が、検索結果一覧にも反映される。検索条件に一致しなくなった場合は、検索結果から外れる。

## 調査メモ

- 通常一覧のタスクは `loadTasks()` で再取得され、選択中タスクも最新データへ差し替えられていた。
- 一方、検索画面の中央一覧は `searchResults` state を別に保持しており、詳細ペイン保存後や期限・タグ・完了状態の更新後に再検索されていなかった。
- そのため、データ保存自体は成功していても、検索結果一覧だけ古い配列を表示し続けていた。

## 修正方針

検索結果再取得処理を `refreshSearchResults()` として共通化し、検索モード中のタスク更新後に `loadTasks()` とあわせて再検索する。

## 検証結果

- Node 20.18.1 環境の `npm run build` は Vite 8 の要求 Node バージョン不足で失敗した。
- 同梱の Node 22.14.0 を PATH 先頭に設定し、`npm.cmd run build` が成功した。
