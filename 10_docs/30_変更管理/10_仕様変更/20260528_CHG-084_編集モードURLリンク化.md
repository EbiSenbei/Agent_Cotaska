# CHG-084 編集モードURLリンク化

## 変更ID

CHG-084

## 変更内容

タスク詳細の本文編集モードで URL を記載した場合、URL 部分を青文字のリンク表示にし、マウスカーソルを当てると「リンク先を表示(Ctrl＋クリック)」と表示する。さらに Ctrl を押しながらクリックした場合は、該当 URL を外部ブラウザ等で開けるようにする。

## 変更理由

現在の編集モードでは URL が通常テキストとして表示されるため、リンクであることが分かりづらく、編集しながらリンク先を確認する操作も直接行いにくい。プレビューモードへ切り替えずに、編集作業中でも URL の視認性とリンク先確認導線を確保したい。

## 想定仕様

### 表示

- 対象はタスク詳細本文の編集モードとする。
- URL と判定された文字列は、編集モード上でも青文字で表示する。
- URL 表示は本文保存データを変更せず、表示上の装飾として扱う。
- 既存の Markdown 編集ハイライト、文字サイズ変更、詳細ペイン拡大表示と競合しないようにする。

### ホバー

- URL にマウスカーソルを当てた場合、「リンク先を表示(Ctrl＋クリック)」と表示する。
- ツールチップまたは同等の UI は、本文編集や選択操作を邪魔しない位置と表示時間にする。

### リンク起動

- URL 上で Ctrl + クリックした場合、既存の外部リンク起動経路を使ってリンク先を開く。
- Ctrl を押していない通常クリックは、従来どおりカーソル移動や選択など編集操作を優先する。
- 対応 URL は `http://` / `https://` を必須範囲とし、必要に応じて `file://` 等の扱いは実装時に確認する。
- URL の末尾に句読点や括弧が続く場合、リンク範囲が過剰に広がらないようにする。

## 影響範囲

- UI: タスク詳細本文の編集モード、ツールチップ表示、クリック操作
- API/IPC: 既存の外部リンク起動 IPC を利用できるか確認。必要な場合のみ追加する
- main process: 外部リンク起動の既存処理確認
- renderer: `DetailPane` 周辺、Markdown 編集ハイライト処理、本文エディタ CSS / イベント処理
- データ: タスクファイル正本と `_index.yaml` のスキーマ変更なし

- 必要に応じて、タスク詳細ペインまたは Markdown 編集ハイライト関連の設計記述

## 実装タスク分解

1. CHG-084-01 設計: タスク詳細編集モードの URL 表示、ホバー文言、Ctrl + クリック動作を設計へ反映する。
2. CHG-084-02 実装: 編集モードで URL を青文字表示し、ホバー表示と Ctrl + クリックによるリンク起動を実装する。
3. CHG-084-03 確認: 編集、選択、通常クリック、Ctrl + クリック、プレビュー表示との整合を確認する。

## 完了条件

- タスク詳細本文の編集モードで、`https://example.com` などの URL が青文字で表示される。
- URL にホバーすると「リンク先を表示(Ctrl＋クリック)」が表示される。
- URL 上で Ctrl + クリックするとリンク先を開ける。
- Ctrl なしのクリックやドラッグ選択は編集操作として従来どおり使える。
- URL 装飾やツールチップが本文保存内容を変更しない。
- プレビューモードのリンク表示・リンク起動に既存の回帰がない。
- Markdown 編集ハイライト、本文文字サイズ変更、詳細ペイン拡大表示と両立する。

## ユーザー確認ポイント

- ホバー文言は「リンク先を表示(Ctrl＋クリック)」でよいか。
- Ctrl + クリックをリンク起動操作とし、通常クリックは編集操作に残す挙動でよいか。
- 初期対応のリンク対象は `http://` / `https://` を必須範囲とすることでよいか。
