# CHG-128 更新参照先GitHub統一

## 変更ID

CHG-128

## 変更内容

Cotaskaインストール版の最新版確認、自動更新、手動ダウンロードの参照先を、Cloudflare R2から`EbiSenbei/cotaska-site`のGitHub Releasesへ統一する。

## 変更理由

リリースノートとNSIS配布3成果物をGitHub Releasesへ集約し、最新版確認だけがR2、自動更新がGitHubという二重管理を解消するため。

## 影響範囲

- UI: 更新確認結果から開くダウンロード先をGitHub Releaseページへ変更
- DB: 変更なし
- API/IPC: 変更なし
- 配布設定: `app-config.yaml`、`package.json`のpublish provider
- main process: GitHub APIによる最新版確認、electron-updaterのGitHub provider利用
- 既存機能影響: 旧Portable版の独自更新は通常配布対象外とし、インストール版への移行を案内
