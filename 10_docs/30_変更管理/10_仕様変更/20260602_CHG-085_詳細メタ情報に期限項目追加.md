# CHG-085 詳細メタ情報に期限項目追加

## 変更ID

CHG-085

## 変更内容

タスク詳細ペイン右側の「▽メタ情報」に表示されている「日付」と「優先度」の間へ、「期限」項目を追加する。日付は既存の `due_date`、期限は `deadline_date` として別々に保存・編集できるようにする。

## 変更理由

詳細ペインのメタ情報内で、タスクの期限を優先度と同じ文脈で確認・変更できるようにしたい。現在の「日付」項目だけでは、利用者が期限として認識したい情報の位置づけが分かりづらいため、画面上の項目名と配置を整理する。

## 想定仕様

### 表示

- 対象はタスク詳細ペイン右側の「▽メタ情報」とする。
- 「日付」と「優先度」の間に「期限」項目を追加する。
- 「期限」は `deadline_date` を表示し、「日付」の `due_date` とは別々に保存する。
- 期限未設定の場合は既存の日付未設定表示と整合する文言にする。

### 編集

- 期限項目から既存の日付変更 UI を起動できるかを確認し、可能であれば既存の `due_date` 編集経路を再利用する。
- 保存形式は `deadline_date` を追加し、既存の `due_date` は日付項目として維持する。

### 設計フェーズの認識合わせ

- 実装前に `10_docs/10_設計/30_画面モック/layout_mock.html` などの画面モックへ反映し、ユーザーと「日付」「期限」「優先度」の並び・表示文言・編集導線を確認する。
- 画面モック確認が完了するまで、実装着手はしない。

## 影響範囲

- UI: タスク詳細ペインの「▽メタ情報」表示、項目順、日付/期限の表示文言、日付変更操作
- DB: Markdown frontmatter に `deadline_date` を追加する。既存 `due_date` は日付項目として維持する
- API/IPC: 原則変更なし。既存のタスク更新 API / IPC で `due_date` を更新する
- 既存機能影響: 今日/明日/次の7日間ビュー、期限表示、日付変更 UI、タスクファイル frontmatter、`_index.yaml` の due_date サマリー
