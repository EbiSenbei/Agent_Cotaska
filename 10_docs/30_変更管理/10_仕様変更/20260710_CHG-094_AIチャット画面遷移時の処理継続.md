# CHG-094 AIチャット画面遷移時の処理継続

## 変更ID

CHG-094

## 変更内容

AIチャットの処理中にユーザーが別画面へ移動しても、実行中のAI処理を中断せずバックグラウンドで継続する。処理中の途中イベントは短期保存し、画面復帰時には処理状態、途中経過、完了結果を確認できるようにする。

また、AIチャットのスレッド一覧では、処理中のスレッド行の右端にアニメーションする処理中アイコンを表示し、現在どのスレッドでAI処理が継続しているかを分かるようにする。

## 変更理由

現状はAIチャット処理中に他画面へ移動すると、処理が中断されたように見える。長時間のAI処理中でもタスク確認や他画面操作を継続できるようにし、明示的な中断操作以外では処理を止めない体験にする必要がある。

## 影響範囲

- UI: AIチャット画面、スレッド一覧の処理中アイコン、画面遷移時の処理中表示、復帰時の途中経過・完了結果表示
- DB: ai_threads / ai_messages / ai_runs の状態保存、必要に応じた実行中状態と途中イベント短期保存の復元
- API/IPC: renderer のライフサイクルに依存しないAI実行管理、途中イベント通知、実行状態取得、途中イベント取得
- 既存機能影響: 明示的な中断、エラー表示、途中経過累積表示、AIチャット履歴保存

## 完了条件

- [ ] AIチャット処理中に別画面へ移動しても、明示的な中断操作なしにAI処理が止まらない
- [ ] AIチャット画面へ戻ったとき、実行中状態、短期保存された途中経過、または完了結果を確認できる
- [ ] AIチャットのスレッド一覧で、処理中のスレッド行の右端にアニメーションする処理中アイコンが表示される
- [ ] 明示的な中断操作は従来どおり実行中処理へ中断要求を送れる
- [ ] エラー、完了、中断の状態が ai_runs / チャット履歴 / UI 表示で矛盾しない

## テスト観点

- [ ] AIチャット送信直後に別画面へ移動し、戻っても処理が継続または完了している
- [ ] 途中経過イベントが短期保存され、画面復帰後も破綻せず再表示される
- [ ] 処理中スレッドの右端に処理中アイコンが表示され、完了・失敗・中断後に消える
- [ ] 明示的な中断操作をした場合だけ `canceled` として扱われる
- [ ] 画面遷移、アプリ終了、エラー発生時の状態保存と復元方針が設計どおりである
