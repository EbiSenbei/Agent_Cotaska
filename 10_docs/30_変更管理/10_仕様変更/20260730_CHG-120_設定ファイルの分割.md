# CHG-120 設定ファイルの分割

## 変更ID

CHG-120

## 変更概要

設定画面で編集しないアプリ配布設定を、利用者設定の `data/settings.yaml` から分離する。更新確認に使う `update.latestVersionUrl` と、利用者確認後に開く `update.downloadPageUrl` は、Portable 配布物の `_app/resources/app-config.yaml` に配置する。

## 変更理由

`data/settings.yaml` は利用者データとして Portable 更新後も保持される。そのため、ここに保存された更新URLは新しいプログラムリリースで変更しても既存利用者へ反映されない。`_app` 配下のアプリ配布設定として管理し、Portable 更新による `_app` 差し替えで更新先の変更を反映可能にする。

## 影響範囲

- UI: 設定画面の項目および操作は変更しない。
- DB: 変更なし。
- API/IPC: 新規チャネルは不要。既存の更新確認・ダウンロード遷移は、分離後のアプリ配布設定を使用する。
- 既存データ: 既存の `data/settings.yaml` にある `update` は読み込み時に更新先の決定へ使わず、保存時にも書き戻さない。その他の利用者設定は保持する。
- 配布: `app-config.yaml` を `_app/resources/` に同梱し、Portable 配布物および `_app` 更新対象に含める。

## 設計書更新

- `10_docs/20_設計/20_基本設計/08_設定画面.md` に、利用者設定とアプリ配布設定の責務、更新URLの読込規則、および設定異常時のフォールバックを追記する。

## 設定ファイルの責務と読込規則

| ファイル | 管理者 | 内容 | 更新方法 |
| --- | --- | --- | --- |
| `data/settings.yaml` | 利用者 | 設定画面で編集する利用者設定 | 通常の設定保存。Portable 更新では保持する。 |
| `_app/resources/app-config.yaml` | 配布側 | 設定画面に出さないアプリ配布設定 | プログラムリリース時に `_app` を更新する。 |

- `update.latestVersionUrl` と `update.downloadPageUrl` は `_app/resources/app-config.yaml` の値を常に採用する。
- `app-config.yaml` が存在しない、YAMLとして不正、または必要なURLが空の場合は、安全なコード内既定値へフォールバックし、原因をアプリログへ記録する。
- アプリは `_app/resources/app-config.yaml` を書き換えない。

## app-config.yaml の初期内容

```yaml
update:
  # 最新版確認に使うURL。Cloudflare R2 の version.json または GitHub Releases latest API 互換JSONを想定します
  latestVersionUrl: "https://pub-d671fdad660b43a8a4b99ede58b7c092.r2.dev/latest/version.json"

  # ダウンロード先: 利用者確認後に開くURL
  downloadPageUrl: "https://ebisenbei.github.io/cotaska-site/download.html"
```
