# CHG-105 ランチャー起動診断と自動復元

## 変更ID

CHG-105

## 変更内容

Portable 版の `Cotaska.exe` ランチャーに、アプリ本体の起動前チェック、起動直後の異常終了検知、利用者向けの復旧ダイアログ、および確認付きの `_app` 自動復元を追加する。

復旧ダイアログでは検出したエラー内容と利用可能な更新前バックアップを表示し、「自動復元へ進む」「バックアップを開く」「エラーログを開く」「閉じる」を提供する。

## 変更理由

Portable 更新が `CotaskaCore.exe` のファイルロックにより途中失敗し、復元も失敗すると、`_app` 内の必須ファイルが欠落して Cotaska が無言で即終了することがある。利用者が原因を把握し、タスク・設定データを変更せずに安全に復旧できる導線が必要である。

## 影響範囲

- UI: 起動失敗時だけ表示する Windows Forms のモーダル復旧ダイアログを追加する。通常起動時には表示しない。
- DB: 変更なし。
- API/IPC: 変更なし。ランチャーから Electron アプリの IPC は使用しない。
- 配布物: `Cotaska.exe`、必要に応じて復元専用の補助実行ファイルまたはスクリプトを更新する。
- 既存機能影響: 通常の `Cotaska.exe` から `CotaskaCore.exe` を起動する動作を維持する。`data/`、`logs/`、`backup/` および利用者が置いた任意ファイルは自動復元の対象外とする。

## 設計方針

### 1. 起動診断

- 起動前に `_app/CotaskaCore.exe`、`icudtl.dat`、`resources.pak`、`snapshot_blob.bin`、`v8_context_snapshot.bin` の存在を確認する。
- 必須ファイルの不足時は本体を起動せず、欠落ファイル名、復旧案内、`launcher.log` への記録を行う。
- 必須ファイルがそろう場合は従来どおり `CotaskaCore.exe` を起動し、起動後の短時間（設計時に確定する監視時間）に異常終了した場合は終了コードと `debug.log` の最新エラーを復旧ダイアログに表示する。
- 正常に起動継続した場合はランチャーを終了する。アプリウィンドウを判定条件にせず、プロセス継続と必須ファイル検査を基本とする。

### 2. 復旧ダイアログ

- 画面には検出内容、最新の有効な `backup/portable-update-before-*.zip`、および「`_app` のみを復元し、利用者データは変更しない」ことを表示する。
- 「バックアップを開く」は `backup` フォルダーをエクスプローラーで開く。
- 「エラーログを開く」は `launcher.log` と存在する場合は `_app/debug.log` を既定アプリで開く。
- 有効な更新前バックアップがない場合は自動復元を無効化し、手動で再配布パッケージから復旧する案内を表示する。

### 3. 確認付き自動復元

- 「自動復元へ進む」の後、復元対象の ZIP、対象が `_app` のみであること、`data/` を変更しないことを示す確認画面を必ず表示する。
- 同じ Portable ルート配下で実行中の `Cotaska.exe` / `CotaskaCore.exe` を検出した場合は、対象プロセスを一覧表示し、利用者の明示確認後に終了を試みる。別のインストール先の Cotaska プロセスは対象にしない。
- 復元時は ZIP を一時フォルダーへ展開して内容を検証し、`_app` だけを置換する。置換失敗時は理由を表示し、ログとバックアップを残す。
- 復元完了後は必須ファイルを再検査し、成功画面から「Cotaskaを起動」を選べるようにする。復元前の `_app` は追加の退避手順を設計時に定義し、復旧失敗時に元へ戻せる状態を確保する。

## 完了条件

- [ ] 必須ファイル欠落時に、欠落ファイル名と復旧案内を含むダイアログが表示される。
- [ ] 本体の起動直後の異常終了時に、利用者が確認可能なエラー内容とログ参照導線が表示される。
- [ ] バックアップ候補と「バックアップを開く」「エラーログを開く」が表示される。
- [ ] 自動復元前に対象・影響・実行中プロセスを確認する画面が表示される。
- [ ] 自動復元は `_app` だけを対象とし、`data/` を変更しない。
- [ ] 復元成功後に必須ファイルを再検査し、Cotaska を起動できる。

## テスト観点

- [ ] 必須ファイルがすべてそろう通常起動ではダイアログを表示しない。
- [ ] `icudtl.dat` などを欠落させた検証環境で、該当ファイル名と復旧導線を表示する。
- [ ] 起動直後に異常終了する検証用本体で、終了検知とログ表示を確認する。
- [ ] 有効な更新前バックアップから `_app` のみを復元し、復元前後で `data/` のハッシュが変わらないことを確認する。
- [ ] 同一ルートの実行中プロセスがある場合とない場合、別ルートの Cotaska がある場合を確認する。
- [ ] ZIP破損、必須ファイル不足、ファイルロックによる復元失敗時に、既存の `_app` とログを保持してエラーを表示する。
