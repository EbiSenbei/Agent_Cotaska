# CHG-080 タスクファイルパスコピー

## 変更ID

CHG-080

## 変更内容

タスク一覧のタスク行右クリックメニューに「パスのコピー」を追加し、対象タスク Markdown ファイルの絶対パスをクリップボードへコピーできるようにする。
あわせて、詳細ペイン下部の登録日時やタスクIDが表示されているフッター部分を右クリックした場合にも「パスのコピー」を表示し、選択中タスクのファイルパスをコピーできるようにする。

## 変更理由

利用者やAIエージェントが、対象タスクファイルを外部ツールや会話へ素早く渡せるようにするため。
現状は詳細ペインの外部アプリ起動導線はあるが、ファイルパスそのものをコピーする手段がない。

## 影響範囲

- UI: タスク一覧の右クリックメニュー、詳細ペイン下部フッター（登録日時・ID表示部分）の右クリックメニュー
- DB: なし
- API/IPC: taskId から main process 側で現在の実ファイルパスを解決し、renderer へ返す IPC の追加または既存 shell API 拡張
- 既存機能影響: タスク右クリックメニュー、詳細ペイン、外部アプリ起動、破損タスク表示
