# CHG-157 AIタスク詳細プレビュー幅

## 変更ID
CHG-157（要求: T-0848）

## 変更内容
AI右プレビューを標準520px、最小480px、最大720pxとする。旧保存幅を範囲内へ補正し、未保存時は標準幅を使う。長いタイトルを省略して右上×を確保する。

## 変更理由
添付画像では幅が狭く、長いタスク名が右上×を表示範囲外へ押し出している。

## 影響範囲
- UI: AI右プレビューの共通枠（ファイル表示も適用）、タスク詳細ヘッダー
- DB / API / IPC: 変更なし
- 幅ドラッグ・保存、タスク編集・ファイル表示を維持する。
