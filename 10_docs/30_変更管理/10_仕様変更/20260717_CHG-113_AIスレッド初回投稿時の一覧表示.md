# CHG-113 AIスレッド初回投稿時の一覧表示

## 変更概要

新しいスレッドで最初のユーザー投稿を送信した時点で、AI応答の完了を待たずにスレッド一覧へ表示する。

## 変更内容

- 新しいスレッドの初回送信前に、スレッドを永続化する。
- 永続化直後にスレッド一覧を再読込し、送信中も作成済みスレッドとして表示する。
- AI応答の成功・失敗・中断時も、初回投稿済みのスレッドを保持する。

## 影響範囲

- UI: `20_app/src/renderer/components/AiChatPane.jsx`
- DB/API/IPC: 変更なし（既存の `aiChat:createThread` を利用）
- 設計書: 基本設計の既存記述と整合するため更新不要

## タスク

1. CHG-113-01 設計書更新要否の確認
2. CHG-113-02 初回投稿前のスレッド作成を実装
3. CHG-113-03 ユーザー確認

## 完了条件

- 新しいスレッドで最初の投稿を送信すると、AIの応答中に左側のスレッド一覧へ表示される。
- AI応答の成否にかかわらず、投稿済みスレッドを一覧から選択できる。

## テスト観点

- Codex SDK と Claude Code の両方で初回送信時に一覧へ即時表示される。
- 送信失敗・中断時にも作成済みスレッドが保持される。
