# Cotaska v0.4.1 リリースノート

- リリース日: 2026-09-01
- 比較対象: v0.4.0リリースコミット `b6fcff7` からv0.4.1リリース準備時点まで

## 概要

Cotaska v0.4.1では、配布・更新経路をGitHub Releasesへ統一し、プロジェクト名の表示を分かりやすくしました。また、AIチャット画面から利用モデルを選択し、プロジェクト設定と同期できるようにしました。

## 主な変更

- CHG-128: 最新版確認、手動ダウンロード、インストール版自動更新の参照先を`EbiSenbei/cotaska-site`のGitHub Releasesへ統一。
- CHG-128: Cotaska公式サイトをインストール版の案内へ更新し、最新版インストーラーをGitHub Release Assetから動的に取得するよう変更。
- CHG-129: 設定画面の「表示名」を「プロジェクト名」へ変更し、ウィンドウタイトルを`Cotaska <プロジェクト名>`形式で表示。
- CHG-130: AIチャット入力欄へモデル選択を追加し、選択中プロジェクトの既定モデルと双方向同期。
- CHG-130: Codex／Claude Codeのモデルをプロバイダーごとに保持し、Amazon Bedrock利用時は設定済みモデルIDを変更不可で表示。

## 配布方式

Windows x64向けNSISインストール版を通常配布の正本とします。インストーラー、自動更新用blockmap、`latest.yml`を同一ビルドから生成し、GitHub Releasesへ一組として公開します。

## 検証

- Node.js 22.14.0 / npm 10.9.2環境で自動テスト24件が成功。
- Rendererの本番ビルドとNSISインストーラー生成が成功。
- インストーラー、blockmap、`latest.yml`のバージョン、参照先、ハッシュ整合性を確認。
- CodexおよびClaudeのWindows実行ファイル同梱を確認。
- `Cotaska.exe`の製品名とアイコンを確認。
- 展開版のRenderer読込と正常終了を起動スモークテストで確認。
