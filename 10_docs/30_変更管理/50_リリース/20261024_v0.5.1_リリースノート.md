# Cotaska v0.5.1

リリース日: 2026-10-24。Windows x64対応。

AIチャットの操作・モデル選択・応答表示を改善し、依存部品を更新しました。Node.js 24系への開発環境移行と、アーカイブ処理の互換性修正を含みます。

## 主な変更

- AIチャットのスレッド操作メニューに、タスクフォルダを開く・名前変更・アーカイブを集約。アーカイブ取消と復元に対応しました。
- モデルと思考量をまとめて選択でき、選択中のモデル名と思考量を表示します。送信待ちの投稿も、追加時点の設定を保持します。
- スレッド切替時に待機時間がリセットされる問題と、画面へ戻った際に完了応答が表示されない問題を修正しました。
- タスクのアーカイブ処理をNode.js 24系のコピー仕様へ対応させました。添付の照合、既存資料の上書き防止、失敗時の元タスク保全を維持しています。
- Electron 44.9.3、Claude Agent SDK 0.3.310、Codex SDK 0.164.0、React 19.3.1、js-yaml 5.5.0、sql.js 1.15.1などへ更新し、間接依存の脆弱性も解消しました。

## ダウンロード

通常のインストール・更新には **Cotaska-0.5.1-win-x64.exe** を使用してください。

| ファイル | 用途 |
|---|---|
| Cotaska-0.5.1-win-x64.exe | Windows x64インストーラー |
| Cotaska-0.5.1-win-x64.exe.blockmap | 自動更新用の差分情報 |
| latest.yml | 自動更新用のバージョン・ハッシュ情報 |
| Cotaska-Portable.zip | 同じビルドから作成した、展開して起動する手動配布物 |
| Cotaska-Portable.zip.sha256 | ZIPのSHA-256チェックサム |

ZIPにタスク・添付・AI履歴などの利用者データは含みません。旧Portable版の`_app/tools/data`構成へ上書きするための更新ZIPではありません。新しいフォルダへ展開して利用してください。

## 検証と実行環境

- 158件の自動テスト、アーカイブ・添付・バックアップ／復元関連のElectronテスト23件が成功。
- AIチャットの並列送信・待機時間・モデル設定・履歴同期、PDF描画・Markdown表示を確認。
- 日本語パスでのビルドとコピーを検証。782ファイルのコピー内容がすべて一致。
- npm auditは全依存・本番依存・セットアップの各対象で0件。
- インストーラーの起動・正常終了、同梱CLI、ソースと配布ASARの一致を確認。

開発・CI・ビルド環境はNode.js 24.22.1／npm 11.19.1です。アプリ本体はElectron 44.9.3の内蔵Node.js 24.22.0で動作します。実AIサービスへの接続や各利用者環境での操作は、自動検証の対象に含めていません。
