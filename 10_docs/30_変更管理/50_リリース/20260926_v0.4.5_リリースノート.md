# Cotaska v0.4.5 リリースノート

## リリース日

2026-10-04

## 概要

タスク表示・別ウィンドウ操作の改善に加え、Cotaska同梱のCodex SDKを更新し、GPT-6.1 Solへ対応した機能・不具合修正リリース。

## 主な変更点

- タスク本文のMarkdownプレビューで、GFM形式の`[ ]`、`[x]`、`[X]`を読み取り専用チェックボックスとして表示するようにした。
- 箇条書き、番号付きリスト、入れ子、引用内のタスクリスト表示に対応した。
- タスク詳細を別ウィンドウで開いた際、親タスク・子タスクをクリックしても表示先が切り替わらない問題を修正した。
- 別ウィンドウ内でタスクを遷移した際、遷移前の編集状態が残らないようにした。
- GitHub Releaseが未作成の正常系を公開可能と判定できるよう、公開スクリプトを安定化した。
- Codex SDKと同梱Codex CLIを0.160.0へ更新した。
- Codexモデル選択肢へGPT-6.1 Solを追加した。
- 既存環境との互換性を優先し、「自動」の既定モデルはGPT-5.6 Terraを維持した。

## 検証内容

- Node.js 22.14.0 / npm 10.9.2でクリーンな依存復元に成功
- Vitest 11ファイル・52テスト成功
- Vite本番ビルド成功
- Codex CLI 0.160.0でGPT-6.1 Solへの実送信に成功
- Electron 44.4.5向けNSISインストーラー生成成功
- `latest.yml`のバージョン、成果物名、サイズ、SHA-512とインストーラーの整合性を確認
- 展開版へのCodexおよびClaudeのWindows実行ファイル同梱を確認
- 展開版のRenderer読込と正常終了を確認
- Cotaska.exeの製品名とCotaskaロゴを確認
