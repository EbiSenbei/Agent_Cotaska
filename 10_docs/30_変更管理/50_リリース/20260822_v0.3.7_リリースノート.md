# Cotaska v0.3.7 リリースノート

- リリース日: 2026-08-22
- 比較対象: v0.3.6リリース準備完了コミット `af5df21` からv0.3.7リリースコミット `ca22762` まで

## 概要

タスクの誤操作をすぐ取り消せる「元に戻す」、ゴミ箱の一括操作、初回利用ガイドを追加しました。AIチャットでは、スレッドを切り替えた際に最新メッセージがすぐ見えるよう改善しています。Portable版の更新中ダイアログも、更新を止めずに最小化または閉じられるようになりました。

## 主な変更

- CHG-121: Portable版の更新中ダイアログを最小化できるようにし、×ボタンで画面を閉じても更新処理がバックグラウンドで継続するよう改善。
- CHG-122: AIスレッドの選択時と履歴読込完了時に、会話の末尾へ自動スクロールして最新メッセージを表示。
- CHG-123: ゴミ箱に「一括戻す」と「一括削除」を追加。一括削除は確認後にタスクをアーカイブへ移動。
- CHG-124: 完了・完了取消、ゴミ箱移動、リスト移動、親子変更、並び替えの直後に「元に戻す」を追加。
- CHG-125: 初回起動時の利用ガイドと、設定画面からガイドを再表示する導線を追加。

## 不具合修正・リリース運用

- BUG-20260822-02: 設定画面で「初回利用ガイドを表示」を押してもガイドが表示されない問題を修正。
- BUG-20260822-01: 制限環境でPortableリリース時の `npm ci` が失敗する事象を調査し、承認付き実行環境を使用するリリース手順を明確化。

## 検証

- Node.js 22.14.0 / npm 10.9.2環境でRenderer自動テストを実行。
- Rendererの本番ビルドが成功することを確認。
- Portable配布物のランチャー、Updater、同梱Codex CLI、必須ファイルを出荷前検証。
- ZIP内Updaterとビルド成果物のSHA-256が一致することを確認。

## 配布物

- `Cotaska-Portable.zip`
- `Cotaska-Portable.zip.sha256`
- `latest/version.json`

## 補足

本リリースノートはGitタグではなく、v0.3.6およびv0.3.7のリリース準備コミットを基準に変更内容を整理しています。
