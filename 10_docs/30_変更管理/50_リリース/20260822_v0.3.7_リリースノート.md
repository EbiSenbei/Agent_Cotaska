# Cotaska v0.3.7 リリースノート

## リリース日

2026-08-22

## 概要

タスク操作の安全性、初回利用時の分かりやすさ、ゴミ箱の管理操作を改善したリリースです。

## 主な変更点

- ゴミ箱内タスクの一括復元・一括アーカイブ操作を追加
- 完了切替、ゴミ箱移動、リスト移動、親子変更・並び替えへ「元に戻す」を追加
- 初回利用ガイドと設定画面からの再表示導線を追加
- 設定画面から初回利用ガイドを表示できない問題を修正
- Portable版Updaterの更新中ダイアログ操作を改善

## 検証内容

- Node.js 22.14.0 / npm 10.9.2でRenderer自動テストを実行
- Renderer本番ビルドを確認
- Portable配布物のランチャー、Updater、同梱Codex CLI、必須ファイルを出荷前検証
- ZIP内Updaterとビルド成果物のSHA-256一致を確認

## 配布物

- `Cotaska-Portable.zip`
- `Cotaska-Portable.zip.sha256`
- `latest/version.json`
