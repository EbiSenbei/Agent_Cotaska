# Cotaska v0.4.4 リリースノート

## リリース日

2026-09-24

## 概要

主要な実行時・開発時依存を更新し、既知脆弱性を解消するとともに、Electron 44へ移行する保守リリース。

## 主な変更点

- Electronを44.4.5へ更新した。
- Chokidar 5、js-yaml 5、markdown-it 15、Vitest 5へ更新した。
- Codex SDK、Claude Agent SDK、React、Vite、electron-builder等を修正版へ更新した。
- 本体とセットアップ資材のsql.jsを1.14.2へ統一した。
- npm監査で検出されていた既知脆弱性を0件まで解消した。

## 検証内容

- Node.js 22.14.0 / npm 10.9.2でクリーンな依存復元に成功
- 自動テスト38件成功
- Vite本番ビルド成功
- Electron 44.4.5向けNSISインストーラー生成成功
- `latest.yml`のバージョン、成果物名、サイズ、SHA-512がインストーラーと一致することを確認
- 展開版にCodexおよびClaudeのWindows実行ファイルが同梱されていることを確認
- 展開版のRenderer読込と正常終了を確認
- Cotaska.exeの製品名とCotaskaロゴを確認
- `npm audit`で既知脆弱性0件
