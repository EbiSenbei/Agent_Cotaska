# Cotaska v0.4.2 リリースノート

- リリース日: 2026-09-06
- 比較対象: v0.4.1公開記録コミット c8287e1 から 1c945fe までの変更と今回の版数更新

## 概要

AIランタイムとモデル選択を更新し、AIチャットの最新応答が表示されない問題を修正しました。画面内のプロジェクト名表示も改善しました。

## 主な変更

- CHG-129: 画面左下のプロジェクト名を設定の表示名と統一し、設定保存時にも反映。
- CHG-131: Codex SDKを0.153.4、Claude Agent SDKを0.3.263へ更新。
- CHG-131: Codexのモデル選択肢にGPT-6 Astraを追加。利用可否はアカウントの提供状況に依存します。
- CHG-131: Claude Codeの新規モデル選択肢と自動選択を更新し、廃止済みモデルの固定既定値を解消。Bedrockの既存モデルID設定は維持。
- BUG-20260906-01: AI応答完了と実行状態の定期確認が競合すると最新応答が表示されない問題を修正。応答完了後に保存済みメッセージを再取得し、表示へ反映。

## 検証

- Node.js 22.14.0 / npm 10.9.2で自動テスト9ファイル・25件が成功。
- Renderer本番ビルドとNSISインストーラ生成が成功。
- インストーラ・blockmap・latest.ymlの版数、参照先、ファイルサイズ、ハッシュ整合性を確認。
- CodexおよびClaudeのWindows実行ファイル同梱を確認。
- Cotaska.exeの製品名とアイコンを確認。
- 展開版のRenderer読込と正常終了を起動スモークテストで確認。

## 配布物
