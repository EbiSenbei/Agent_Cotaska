# Cotaska v0.5.3

リリース日: 2026-11-19

## 主な変更

- **Codex新モデルに対応**：GPT-6.2 SolとGPT-6.2 Astraを設定画面・AIチャットから選択できます。思考量の軽・中・高にも対応します。
- **自動モデルを更新**：Codexの「自動」はGPT-6.2 Solを使用します。明示的に選択済みのモデルは維持します。
- **起動時の白画面対策**：初回画面の読み込みとサービス初期化の順序を調整し、読み込みが停滞した場合の有限回の再試行と起動診断を追加しました。
- **実行基盤・依存部品を更新**：Electron 44.11.5、内蔵Node.js 24.22.3、Codex SDK/CLI 0.170.0、Claude Agent SDK 0.3.328、PDF.js 6.5.438、sql.js 1.17.0を採用しました。開発・テスト関連と間接依存も更新しています。

## 利用方法・確認事項

- 新モデルは設定画面またはAIチャットのモデル選択から選べます。利用可能なモデルはアカウント・プランに依存します。
- タスク・添付・設定・AI履歴の保存形式は変更していません。
- 起動対策と新モデルの利用者による実環境確認は継続して追跡します。

## 検証・配布

- 自動テスト237件と隔離Electronの画面検証6種類が成功しました。
- 起動の通常・40秒遅延後の復帰・初回読み込み失敗後の再試行を確認しました。
- 全依存・本番依存・セットアップ用依存のnpm監査はいずれも0件でした。
- 配布アプリの起動・正常終了、同梱Codex/Claude CLI、更新情報のサイズとSHA-512、本番依存12部品とMain/Renderer244ファイルの一致を確認しました。
- GPT-6.2 Sol/Astraの実応答とSolのスレッド再開は、依存更新時に同じSDK/CLIで確認済みです。

通常のインストールと自動更新にはCotaska-0.5.3-win-x64.exeを使用してください。互換ZIPは新しいフォルダへ展開して利用するための配布物です。旧Portable環境への上書き更新用ではありません。
