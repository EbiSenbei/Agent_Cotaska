# Cotaska 変更管理目次

この配下は現行仕様の正本ではなく、変更・検証の経緯を保存する履歴資料である。現在の動作は `../20_設計/README.md` を参照する。

| フォルダ | 内容 |
| --- | --- |
| `10_仕様変更` | CHG-xxx ごとの仕様変更記録。該当する現行設計へのリンクを記載する。 |
| `20_バグレポート` | 不具合報告と対応経緯。 |
| `40_DBスクリプト` | DB初期化・変更用スクリプト。 |
| `50_リリース` | リリースノート・配布記録。 |

過去資料はファイル名とGit履歴を維持して再配置している。移動前の履歴は `git log --follow -- <ファイルパス>` で追跡する。
