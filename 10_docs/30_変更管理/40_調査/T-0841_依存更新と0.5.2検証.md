# T-0841 依存更新・Cotaska0.5.2検証

実施日: 2026-10-28。関連：T-0841〜T-0844。

## 採用範囲

製品版数を利用者の指定どおり0.5.1から0.5.2へ変更。Electron44.10.0、Claude SDK0.3.312、Codex SDK0.165.0、sql.js1.15.2、electron-builder26.18.1、electron-updater6.8.12を採用した。本体・setupのSQL版を統一し、SDKの完全固定とその他のcaret方針を維持する。Electron45・chokidar6へのメジャー移行、npm12、rcedit代替は別途検証とした。

機能・公開IPC・データ形式の変更は不要。SQLは既存のCOMMIT後にexportするため1.15.2の書込みtransaction中export禁止へ追加修正なしで適合する。製品ソースは変更せず、manifest／lockと構成資料・記録を更新した。

## 検証結果

- Node.js 24.22.1／npm 11.19.1で、45ファイル201テスト成功（SQLの実DB transaction commit／rollback・保存再読込み、監視連携を含む）。
- 全依存・本番依存・setupのnpm auditは各0件。npm ls --depth=0に欠落・invalidなし。
- Electron隔離UI検証6種成功：並列送信、待機時間、履歴同期、思考量設定、タスクデータ保存、PDF描画／Markdown表示。実AI通信は未実施。
- Codex公開型定義は旧版と同一。Claudeの使用中APIは維持。SDK import・Codexローカルクライアント生成成功。
- 開発側と配布側のCLI起動成功：codex-cli 0.165.0／Claude Code 2.1.312。
- npm run dist:installer成功。配布実行基盤はElectron44.10.0／Node24.22.1。製品EXEの名称・版数0.5.2を確認。
- 展開版の隔離userData・独立instanceによるRenderer読込と正常終了を確認。通常版プロセスを停止・置換しない。
- 配布ASARの本番直接依存12部品はロック版と一致。Main・Rendererの240ファイルはソースとSHA-256一致。
- latest.ymlの版数・参照ファイル名・インストーラーサイズとSHA-512が一致。EXE／blockmap／latest.ymlは同一ビルド。

## 保全・制約

利用者のタスク・添付・設定・AI履歴へ検証データを投入しない。テストは既存の一時プロジェクト・独立userDataで実施し、稼働中のインストール済みCotaskaは保持した。既存の別件差分は維持する。外部公開・通常環境への配布・コミット／pushは行わない。利用者による実認証・実AI・更新導線の確認はT-0844を未完了で追跡する。

作業前manifest／lock／SDK型、監査JSON、ロック差分、テストと画面検証ログ、インストーラービルドログ、配布照合JSONはリポジトリ外のworkspace/T-0841/に保持する。
