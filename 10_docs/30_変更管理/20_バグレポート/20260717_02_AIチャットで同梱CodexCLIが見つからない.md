## 現象

タスクマスター配下のCotaskaでAIチャットを送信すると、`Bundled Codex CLI binary was not found` が表示される。

## 再現手順

1. `00_mgmt/Cotaska_タスク管理ツール/Cotaska.exe` を起動する。
2. AIチャットでメッセージを送信する。
3. 同梱Codex CLIの探索エラーが表示される。

## 期待動作

Portable版に同梱されたCodex CLIが解決され、AIチャットを実行できる。

## 調査メモ

開発環境と `20_app/release/win-unpacked`、`20_app/release/Cotaska-Portable` には `codex.exe` が存在する。一方、実行対象の `00_mgmt/Cotaska_タスク管理ツール/_app/resources` には `app.asar` しかなく、`app.asar.unpacked` が同期されていなかった。Electron Builderの同梱設定ではなく、タスクマスターへ配布物全体を同期していないことが直接原因である。また、出荷前検証が `app.asar` の存在だけを確認しており、この欠落を検出できなかった。

## 修正方針

- リリース生成時にCodex CLI実体の存在を必須検証する。
- ZIP内にもCodex CLI実体が含まれることを検証する。
- タスクマスター同期の前後でCodex CLI実体を検証し、不完全な `_app` を配備できないようにする。
- 最新のPortable成果物をタスクマスターへフォルダ単位で再同期する。

## 検証結果

- タスクマスター同期先の `codex.exe` の存在を確認した。
- 同期先CLIで `codex.exe --version` を実行し、`codex-cli 0.144.1` を確認した。
- PowerShell Parserで `release-all.ps1` と `sync-task-master-release.ps1` の構文エラーがないことを確認した。
- 同梱Node.js 22.14.0 / npm 10.9.2で `npm run build` が成功した。
- 2026-07-17、ユーザーによるAIチャット送信確認が完了し、問題解決を確認した。
