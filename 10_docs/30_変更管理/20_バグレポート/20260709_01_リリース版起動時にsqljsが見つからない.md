## 現象

リリース同期後の Cotaska 起動時、main process で `Cannot find module 'sql.js'` が発生し、アプリが起動できない。

## 再現手順

1. `20_app/release-all.ps1` を実行する。
2. `20_app/sync-task-master-release.ps1` を実行する。
3. `00_mgmt/Cotaska_タスク管理ツール/Cotaska.exe` を起動する。

## 期待動作

`sql.js` を含む必須ランタイム依存が配布物に含まれ、アプリが起動する。

## 調査メモ

- `package.json` と `package-lock.json` には `sql.js` と `@openai/codex-sdk` が定義されていた。
- `node_modules/sql.js` と `node_modules/@openai/codex-sdk` が存在しなかった。
- `npm ls sql.js @openai/codex-sdk --depth=0` は空を返した。
- 前回ビルド時の electron-builder 出力にも、両パッケージの missing 警告が出ていた。
- `release-all.ps1` は依存復元を行わず `npm run dist:dir` に進むため、依存不足のまま壊れた配布物を作成できていた。

## 修正方針

- `release-all.ps1` のビルド前に `npm ci --no-audit --no-fund` を実行し、lockfile に基づいて依存関係を復元する。
- `sql.js` は `require.resolve`、ESM package の `@openai/codex-sdk` は dynamic `import()` で検証し、欠けている場合はリリース工程を停止する。
- 修正後にリリースと同期を再実行し、配布先の起動に必要な依存が含まれることを確認する。

## 検証結果

- `20_app/release-all.ps1` が成功した。
- 前回出ていた electron-builder の `missing: @openai/codex-sdk` / `missing: sql.js` 警告が消えた。
- `20_app/sync-task-master-release.ps1` が成功した。
- 同期後の `00_mgmt/Cotaska_タスク管理ツール/_app/resources/app.asar` に `node_modules/sql.js` と `node_modules/@openai/codex-sdk` が含まれることを確認した。
- 同期後の `Cotaska.exe` を短時間起動し、ランチャーが exit code 0 で終了し、`CotaskaCore` が起動することを確認した。
