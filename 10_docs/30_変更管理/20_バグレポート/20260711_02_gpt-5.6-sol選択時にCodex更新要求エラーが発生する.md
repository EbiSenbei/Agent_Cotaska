## 現象

CotaskaでCodexによるチャットを利用していたところ、次のHTTP 400エラーが発生し、チャットを継続できない。

```json
{"type":"error","status":400,"error":{"type":"invalid_request_error","message":"The 'gpt-5.6-sol' model requires a newer version of Codex. Please upgrade to the latest app or CLI and try again."}}
```

エラーメッセージ上は、選択された `gpt-5.6-sol` に対して、Cotaskaから利用しているCodex AppまたはCLIのバージョンが古いことが示されている。`gpt-5.6-sol` のリリースとの関連は未確認であり、調査で確定する。

## 再現手順

1. CotaskaでCodexのAIチャットを開く。
2. `gpt-5.6-sol` が選択された状態でメッセージを送信する。
3. AIチャットの応答またはエラー表示を確認する。

## 期待動作

利用可能なモデルを選択した場合はチャットが正常に実行される。利用中のCodexバージョンがモデルに未対応の場合は、送信前またはエラー発生時に、必要な更新操作や利用可能な代替モデルが利用者に分かる形で案内される。

## 調査メモ

- CotaskaはグローバルにインストールされたCodex App／CLIではなく、`@openai/codex-sdk` のプラットフォーム別パッケージに同梱されたCodex CLIを明示的に起動している。
- 修正前の依存バージョンと同梱CLIはともに `0.142.3` だった。
- 2026-07-11調査時点のnpm安定版は `@openai/codex-sdk 0.144.1` で、更新後の同梱CLIも `codex-cli 0.144.1` となることを確認した。
- OpenAIの公開ドキュメント／公式サイト検索では `gpt-5.6-sol` の個別公開情報を確認できなかったため、モデルのリリース経緯は断定しない。
- 更新後の `codex-cli 0.144.1` で `gpt-5.6-sol` を明示指定した疎通確認が成功し、元のHTTP 400エラーは再現しなかった。

## 修正方針

Cotaskaが実際に使用する `@openai/codex-sdk` と同梱Codex CLIを安定版 `0.144.1` へ更新する。また、将来同種のモデル互換性エラーが発生した場合は、生のJSONエラーではなく、Cotaska本体の更新が必要であることを利用者へ案内する。

## 修正内容

- `20_app/package.json` と `20_app/package-lock.json` の `@openai/codex-sdk` を `^0.144.1` へ更新した。
- `codexSdkService.js` にCodex更新要求エラーの判定を追加した。
- 該当時は「最新版のCotaskaへ更新してください」と代替モデルの利用を案内する日本語メッセージを返すようにした。

## 検証結果

| 確認項目 | 結果 |
|---|---|
| `codexSdkService.js` 構文確認 | 成功 |
| SDK依存解決 | `@openai/codex-sdk 0.144.1` / `@openai/codex 0.144.1` |
| 同梱CLIバージョン | `codex-cli 0.144.1` |
| `gpt-5.6-sol` 疎通確認 | 読み取り専用・一時セッションで `OK` 応答、HTTP 400なし |
| Vite本番ビルド | Node.js 24.14.0で成功（104 modules transformed） |

既定Node.js 20.18.1ではVite 8の要件（20.19以上）を満たさずビルドできなかったため、Codex同梱Node.js 24.14.0で再検証した。これは今回の修正による失敗ではない。

## 終了結果

2026-07-11にユーザー確認を受け、修正・検証結果を承認して本不具合を完了とした。
