# BUG-20261024-03 Node.js 22.23.4の大規模コピーで異常終了

報告日: 2026-10-24。状態: ユーザー確認待ち。重要度: 中（開発用ランタイムの制約）。対象: T-0791、T-0792、追跡T-0806。

## 現象・再現手順

開発用Node.js 22.23.4で`fs.cpSync(sourceTasks, isolatedDestination, { recursive: true })`を実行すると、コピー先にファイルを書き込む前に終了コード-1073741819（0xC0000005）となる。同一ソースのコピーを22.14.0では完了できる。単一ファイルの小規模コピーは22.23.4でも成功する。

証跡・再現スクリプト: リポジトリ外の`../workspace/T-0791/copy-check.cjs`。既存の日本語パス配下のtasks（約800ファイル）から、検証用の新規フォルダへのコピーのみを行う。元データは変更しない。プロセス異常終了の原因や影響条件は未確定。

## 切り分け・暫定対応

- Node.js 22.14.0: 同一コピー成功。
- Node.js 22.23.4: 同一コピーで異常終了を2回確認。
- 配布Electron 44.9.3／内蔵Node.js 24.22.0: 同一コピー成功（electron-copy.json）。アプリのバックアップ／復元テストも成功。
- 依存更新の既存データ検証はPythonで隔離コピーを作成し、更新後のライブラリでタスク・設定・AI DBの読書きを確認済み。
- 開発・CI・ビルドの通常経路とNSIS生成は別途検証する。最低セキュリティ版を下げない。

## 未完了・クローズ条件

最小再現条件と原因を確認し、公式修正版または検証済みの回避方法を記録する。セキュリティ最低版を維持して大規模コピーが成功し、アプリの既存データ・バックアップ／復元の回帰がないことを確認して閉じる。

## 2026-10-24 T-0806の追加調査

状態は調査中（原因判断・回避方法の検証結果を記録済み、製品適用は未実施）。詳細は`10_docs/30_変更管理/40_調査/T-0806_Node22_fs.cpSync異常終了調査.md`。

- Windows x64・コードページ932では日本語のコピー元／コピー先ディレクトリパスで空フォルダも異常終了する。英数字パスなら800ファイル成功。大規模コピーに固有の問題ではなく、異常終了コードは0xC0000005／0xC0000409。
- 22.17.0に導入されたネイティブ再帰コピー／上書き経路で、22.23.4には非ASCIIパス変換の公式修正PR #61950が入っていない。実測・ソース・公式差分から当該変換不備が原因と判断する。クラッシュダンプによる発生命令の特定は未実施。
- 24.15.0に公式修正収録。最新22系は22.23.4で後続修正版は確認できない。セキュリティ版24.22.1と配布Electron 44.9.3は日本語・空フォルダ・上書き等各24条件すべて成功。
- 22.23.4の`fs.promises.cp`は新規・上書きとも成功。同期の手動再帰コピーも新規コピーで成功。フィルター追加のみでは日本語ファイルの上書きで異常終了または失敗し、コピー先旧ファイルの削除後に失敗するケースも確認したため、一般的な修正案にしない。
- 利用者tasks782ファイルの不変スナップショットを使い、22.23.4の非同期・手動再帰・新規フィルター付き、および24.22.1／Electron通常コピーの全SHA-256一致を確認。22.23.4の通常コピーは0ファイルで異常終了。検証先以外の元データは保持。

推奨は最低版22.23.4を維持し、対象コピーを非同期コピーへ変更するか、同期要件に合わせた再帰コピーを実装すること。24.22.1への移行は開発・CI・ビルド全体の互換検証が別途必要。製品適用、日本語パス・上書き・失敗時の回帰検証、既存バックアップ／復元、必要な利用者確認が残るため、本票をクローズしない。
