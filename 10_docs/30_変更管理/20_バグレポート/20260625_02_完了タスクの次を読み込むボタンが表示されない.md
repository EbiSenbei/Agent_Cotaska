## 現象

CHG-083「完了タスク遅延読み込み」では、初期表示分を超える完了タスクを「次を読み込む」などのボタン操作で追加読み込みできる仕様になっている。
しかし、タスクが100件以上ある状態でも、古い完了タスクを追加読み込みするためのボタンが画面上に見当たらない。

## 再現手順

1. 完了タスクが初期読み込み件数を超える状態の Cotaska を起動する。
2. 完了タスクを確認できるビューを開く。
3. 古い完了タスクを追加読み込みするボタンの有無を確認する。

## 期待動作

初期表示分を超える完了タスクが存在する場合、完了ビューで「次を読み込む」などの明示操作により古い完了タスクを追加読み込みできる。

## 調査メモ

- 2026-06-25: T-0311 の内容をもとに起票。原因調査中。
- 2026-06-25: 参照仕様は `10_docs/20_実装準備/40_仕様変更管理/20260527_CHG-083_完了タスク遅延読み込み.md`。
- 2026-06-25: `_index.yaml` 上の完了タスクは 276 件あり、既定の初期読み込み件数 100 件を超えているため、仕様上は追加読み込み導線が必要な状態。
- 2026-06-25: main process 側には `tasks:getCompletedPage` IPC があり、`taskService.getCompletedTaskPage()` は `hasMore: allSummaries.length > limit` を返す実装になっている。API 側のページング導線は存在する。
- 2026-06-25: renderer 側の `App.jsx` では、完了ビュー `activeNav === "完了"` のとき `visibleTasks = completedTasks` としている一方、`useProgressSections = !isSearchMode && activeNav !== "ゴミ箱"` のため完了ビューでも進捗セクション化が有効になる。
- 2026-06-25: 完了ビューの `completedTasks` は `progressStatus === "完了"` と判定され、`progressSections` に「完了」セクションとして入る。
- 2026-06-25: `MainPane.jsx` の「次を読み込む」ボタンは `renderFlatList()` 内にのみあり、`progressSections` が存在する場合は `renderProgressSections()` が選ばれるため、完了ビューではボタン描画に到達しない。
- 2026-06-25: 主因は、完了ビューを進捗セクション表示の対象から除外していないこと。main 側の追加読み込み API ではなく、renderer の表示分岐不整合が原因。
- 2026-06-25: `App.jsx` の `useProgressSections` 条件から完了ビューを除外し、完了ビューでは `MainPane` のフラットリスト描画が使われるように修正。

## 修正方針

- `App.jsx` の `useProgressSections` 条件から完了ビューを除外し、`activeNav === "完了"` では `MainPane` が `renderFlatList()` を使うようにする。
- もしくは `MainPane.jsx` の `renderProgressSections()` にも完了ビュー用の追加読み込みボタンを表示する。ただし、完了ビューは進捗ごとの移動対象ではないため、完了ビューを進捗セクション化しない方針がより小さい修正。
- 修正後は、完了タスクが100件超の状態で完了ビュー下部に「次を読み込む」が表示され、クリックごとに `completedLoadMoreLimit` 件ずつ追加表示されることを確認する。

## 対応内容

- `App.jsx` の進捗セクション適用条件を変更し、`activeNav === "完了"` の場合は進捗セクション化しないようにした。
- 既存の `MainPane.jsx` 側の「次を読み込む」ボタンと `tasks:getCompletedPage` / `completedHasMore` の流れをそのまま利用する。

## 検証結果

- 2026-06-25: 通常の `npm run build` はローカル Node.js `v20.18.1` が Vite の要求バージョンを満たさず失敗。
- 2026-06-25: Codex 同梱 Node.js `v24.14.0` を PATH 先頭に置いて `npm run build` を実行し、成功。
