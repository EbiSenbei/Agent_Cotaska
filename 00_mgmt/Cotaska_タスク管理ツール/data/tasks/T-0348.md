画面右のコンテキストパネルの幅を変更できるようにしてほしい

## 対応メモ

- AIモード右側のコンテキストパネル左端に、幅変更用のドラッグハンドルを追加。
- パネル幅は 320px から 720px の範囲で変更可能。
- 変更した幅は `localStorage` に保存し、画面を開き直しても前回幅を復元する。
- 1280px以下の画面で右パネルがオーバーレイ表示になる場合も、保存済みの幅を反映する。

## 検証

- `node --check 20_app/src/main/preload.js`
- `node --check 20_app/src/main/main.js`
- 同梱 Node.js v24.14.0 で `npm run build` 成功。

## 確認待ち

- 実画面でAIモード右側のコンテキストパネル左端をドラッグし、幅を変更できること。
- 画面を開き直しても、変更した幅が復元されること。
