画面右のサイドパネルであるコンテキストパネルについて、
以下の対応をしてほしい
　・初期は非表示としてほしい
 　　⇒OK
　・非表示とするボタンを右上とかに追加してほしい
　　⇒OK
　・[T-XXXX]とタスクが呼ばれたときにはタスク詳細
　　それ以外のテキストファイルが呼ばれたときには、エディタを表示してほしい
　　可能であればPDFが呼ばれたらPDFビューワを表示してほしい
 　・画面左の「フォルダ(ファイルツリー」)にてクリックされたときも
　　上記と同様、以下のように開いてほしい
　　・[T-XXXX]とタスクが呼ばれたときにはタスク詳細
　　・それ以外のテキストファイルが呼ばれたときには、エディタを表示してほしい
　　・可能であればPDFが呼ばれたらPDFビューワを表示してほしい

## 対応結果

- AI画面の右コンテキストパネルを初期非表示に変更。
- 右コンテキストパネル右上に閉じるボタンを追加。
- チャット本文の `T-XXXX` リンクをクリックした場合、右コンテキストパネルにタスク詳細を表示するよう変更。
- 作業フォルダツリーでファイルをクリックした場合、右コンテキストパネルを開くよう変更。
  - `T-XXXX.md` はリストモードのタスク詳細と同じ `DetailPane` で表示。
  - テキスト系ファイルは読み取り専用エディタで表示。
  - PDFファイルはPDFビューアで表示。
- ファイルプレビュー用の `aiChat:previewFile` IPCを追加。
- AI右コンテキストパネルのタスク表示を独自カードではなく、リストモードと同じタスク詳細サイドパネルへ変更。
- テキスト/PDFファイルビューは右コンテキストパネルの表示領域をいっぱいに使うようにし、テキストエディタの手動リサイズを廃止。
- ファイルビュー右上に、タスク詳細と同じ `↗` アイコンの「外部アプリで開く」ボタンを追加。
- Markdownファイルのファイルビュー右上に、タスク詳細と同じ `🔍` / `✏` アイコンのプレビュー切替ボタンを追加。
- AI右コンテキストパネル内のタスク詳細は枠・角丸・内側余白を外し、サイドパネルいっぱいに表示するよう調整。

## 検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。
