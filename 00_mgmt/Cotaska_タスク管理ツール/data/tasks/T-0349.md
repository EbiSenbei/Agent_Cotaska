新しいスレッドでAIチャットをすると以下のエラーとなる。

確認が必要
Wrong API use : tried to bind a value of an unknown type (undefined).

## 原因

新しいスレッドで送信する場合、`thread_id` がまだ存在しないため `undefined` になる。

`codexSdkService.sendMessage()` がこの `undefined` のまま `aiService.getThread(inputThreadId)` を呼び、
sql.js の `bind()` に `undefined` が渡っていた。

sql.js は `undefined` をバインドできないため、
`Wrong API use : tried to bind a value of an unknown type (undefined).`
で失敗していた。

## 対応メモ

- `codexSdkService.sendMessage()` で、`thread_id` がある場合だけ既存スレッドを検索するように修正。
- `thread_id` がない場合は、そのまま新規AIスレッドを作成する。
- `aiService` の `run()` / `query()` でSQLパラメータの `undefined` を `null` に正規化する防御処理を追加。

## 検証

- `node --check 20_app/src/main/aiService.js`
- `node --check 20_app/src/main/codexSdkService.js`
- `node --check 20_app/src/main/main.js`
- `node --check 20_app/src/main/preload.js`
- 同梱 Node.js v24.14.0 で `npm run build` 成功。

## 確認待ち

- AIモードで「新しいスレッド」を選択した状態からチャット送信し、エラーにならず新規スレッドとして会話できること。
