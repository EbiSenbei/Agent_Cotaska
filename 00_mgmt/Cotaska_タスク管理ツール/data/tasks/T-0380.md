## 背景

Cotaska起動時に Electron のエラーダイアログで以下のエラーが表示されたが、ログが残っていないように見える。

- `A JavaScript error occurred in the main process`
- `Error: Cannot find module 'sql.js'`
- 発生箇所候補: `src/main/aiService.js` の `require('sql.js')`

## 対応内容

- main process の初期化中に発生した例外を、画面表示前でもログファイルへ出力できるようにする。
- `uncaughtException` / `unhandledRejection` / Electron 起動初期化エラーの記録箇所を確認する。
- `sql.js` の読み込み失敗時に、require stack と実行環境情報がログに残るようにする。

## 完了条件

- 同種の起動時エラー発生時にログファイルへエラー内容とスタックトレースが出力される。
- ログ出力先が確認でき、ユーザーへ案内できる。
- 既存の正常起動に影響しないことを確認する。

## 対応メモ

- `20_app/src/main/earlyStartupLogger.js` を追加し、`main.js` の先頭で `uncaughtException` / `unhandledRejection` / process warning のログ出力を登録した。
- `appLogger` 初期化後は早期ロガーから既存 app log にもミラーするようにした。
- `aiService.js` の `sql.js` 読み込みを `openAiService()` 時の遅延 require に変更し、失敗時に require stack、DB パス、実行環境情報をログに残すようにした。
- Electron の `child-process-gone` を app log に記録するようにした。
- バグレポート: `10_docs/30_変更管理/20_バグレポート/20260709_02_起動時main_processエラーのログ未出力.md`

## 検証

- `node --check 20_app/src/main/earlyStartupLogger.js`
- `node --check 20_app/src/main/main.js`
- `node --check 20_app/src/main/aiService.js`
- `node -e "require('./20_app/src/main/aiService'); console.log('aiService require ok')"`
- `sql.js` の `MODULE_NOT_FOUND` を疑似発生させ、ログに `MODULE_NOT_FOUND` と `requireStack` が残ることを確認。

結果: 上記は成功。`npm run build` は Node.js 20.18.1 が Vite の要求する 20.19+ を満たさないため未完了。ユーザー確認待ち。
