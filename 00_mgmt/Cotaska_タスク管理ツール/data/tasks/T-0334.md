「タスク詳細画面」のどこかに「AIへチャット」ボタンを追加
（どこに追加するか？は画面モックを作成し、協議）

「AIへチャット」ボタンが押下されたら、
「AI」画面へ遷移し、新しいスレッドを立てて、
対象のタスクを添付ファイルにつけた状態にしてほしい

## 対応結果

- タスク詳細ヘッダー右上のアクション群に「AI」ボタンを追加。
- 「AI」ボタン押下時にAI画面へ遷移するようにした。
- 押下したタスクを対象に、新しいAIスレッドを作成するIPC `aiChat:createTaskChatThread` を追加。
- 新規AIスレッドには `primary_task_id` として対象タスクIDを設定する。
- 対象タスクのMarkdownファイルを参照ファイルとして自動追加する。

## 検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。
