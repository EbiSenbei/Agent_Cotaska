CodexSDKからの処理待ちの時、待機している秒数を表示してほしい

## 対応結果

- Codex SDK送信中に待機秒数をカウントする状態を追加した。
- 処理中メッセージ内に `待機 N秒` を表示するようにした。
- 送信開始時に0秒から開始し、1秒ごとに更新する。
- 送信終了時は待機秒数をリセットする。

## 検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。
