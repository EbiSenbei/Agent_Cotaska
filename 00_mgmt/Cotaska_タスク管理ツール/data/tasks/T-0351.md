アーカイブボタンが、今は[active]とあるが、添付の画像のように
カバンのアイコンにして惜しい
また、アーカイブボタンを押しても、スレッド一覧から消えない。

## 対応メモ

- AIスレッド一覧の `active` ステータスバッジ表示を廃止。
- 添付画像のCodexスレッド一覧に近い形で、スレッド行の右端に小さなアーカイブアイコンボタンを追加。
- アーカイブボタン押下時に `aiChat.archiveThread(threadId)` を呼び出すように変更。
- アーカイブ後はスレッド一覧を再読み込みし、アーカイブ済みスレッドが通常一覧から消えるようにした。
- 選択中スレッドをアーカイブした場合は、次のスレッドを自動選択し、候補がなければチャット表示をクリアする。

## 検証

- `node --check 20_app/src/main/main.js`
- `node --check 20_app/src/main/preload.js`
- 同梱 Node.js v24.14.0 で `npm run build` 成功。

## 確認待ち

- スレッド行の右端にアーカイブアイコンが表示されること。
- アーカイブアイコンを押すと対象スレッドが一覧から消えること。
- 選択中スレッドをアーカイブしても画面が不整合にならないこと。
