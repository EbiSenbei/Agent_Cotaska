T-0514で採用したcopy toastとmodalについて、Enter / Exit、unmount、連続操作、Reduced motionを含む実装可能な入退場仕様を確定する。

## 設計対象

- copy toastは画面下辺との空間関係を維持し、`opacity: 0; transform: translateY(100%)`から定位置へ`var(--motion-standard) var(--ease-out)`でEnterする
- copy toastのExitは同じ下辺へ`var(--motion-fast) var(--ease-out)`で戻し、完了後にunmountする
- modalはoverlayのopacityと、中央をtransform originとするdialogの`opacity + scale(.97)`を組み合わせる
- modalのEnterは`var(--motion-standard)`、Exitは`var(--motion-fast)`を基準とし、ごみ箱確認とAIスレッド名変更で共通化する
- `prefers-reduced-motion: reduce`では移動・拡縮を使わず、opacityだけを120msで補間する
- transition完了イベントとfallback timeoutを含むlifecycle、連続操作時のretarget、終了中の操作可否を定義する

## 完了条件

- 初期、Enter中、表示中、Exit中、unmount後の状態遷移が明記されている
- 表示時間、transition時間、easing、transform origin、終了条件が正確な値で示されている
- 成功・失敗toastの意味、`aria-live`、modal semantics、キーボード操作を損なわない
- 新規依存を追加せず、既存の共通モーショントークンを再利用する方針になっている
- 必要な設計書とテスト観点が更新されている

## 実施結果

- 共通設計書へUnmounted / Enter / Settled / Exitの状態遷移を追加した
- toastはEnter 160ms、表示2400ms、Exit 120ms、modalはEnter 160ms、Exit 120msに確定した
- 自身の`opacity` transitionendと200ms fallback timeoutを終了条件にし、再表示時は現在値からretargetする方針とした
- modalの全close経路、Exit中の二重操作防止、`aria-live`、dialog semantics、Reduced motionの扱いを確定した
- 新規依存を追加せず、共通モーショントークンとCSS transitionを再利用する
