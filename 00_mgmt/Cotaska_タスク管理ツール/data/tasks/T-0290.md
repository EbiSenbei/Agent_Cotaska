編集モードURLリンク化の動作を、編集操作とリンク起動の両面から確認する。

## 確認ポイント

- `https://example.com` が編集モードで青文字表示される。
- URL ホバー時に「リンク先を表示(Ctrl＋クリック)」が表示される。
- Ctrl + クリックでリンク先を開ける。
- 通常クリックはカーソル移動として動作する。
- URL を含む行の文字入力、削除、範囲選択が問題なく行える。
- Markdown プレビュー側のリンク挙動に回帰がない。

## 確認結果

- ユーザー確認により動作確認OK。
