タスク詳細本文の編集モードで URL を青文字表示し、ホバー表示と Ctrl + クリックによるリンク起動を実装する。

## 完了条件

- 編集モードの URL が青文字で表示される。
- URL ホバー時に「リンク先を表示(Ctrl＋クリック)」が表示される。
- Ctrl + クリックでリンク先を外部ブラウザ等で開ける。
- Ctrl なしのクリック、ドラッグ、範囲選択、文字入力が従来どおり動作する。
- URL 装飾は本文保存内容を変更しない。
- プレビューモードのリンク表示・リンク起動に回帰がない。

## 実施結果

- 編集モードの Markdown ハイライトで `http://` / `https://` の生URLを青文字表示するようにした。
- URLホバー時に「リンク先を表示(Ctrl＋クリック)」を表示し、Ctrl + クリック時に既存の `shell.openTaskTarget` 経路でリンク先を開くようにした。
- 通常クリック、入力、選択は textarea の編集操作を優先する実装とした。
