外部のエクスプローラから、チャット欄にファイルをドラッグした時に
それを添付ファイルとして扱ってほしい

## 対応結果

- AIチャット入力欄への外部ファイルドロップを検知し、参照ファイルとして追加する処理を追加。
- main process 側でドロップされたファイルパスを参照ファイル形式へ正規化するAPIを追加。
- 作業フォルダ内のファイルは相対パス、作業フォルダ外のファイルは絶対パスで管理する。
- Codex送信時は、作業フォルダ外のファイルもCotaskaが直接読み取り、コピーせずに参照コンテキストとして渡す。
- 存在しないファイル、フォルダは参照ファイル追加対象外とする。
- Electron 41では外部ドロップ時の `file.path` が空になる場合があるため、preloadで `webUtils.getPathForFile(file)` を使って実パスを取得するように修正。

## 検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。
