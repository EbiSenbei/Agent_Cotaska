## 目的

タスク一覧の右クリックメニューと詳細ペインから、対象タスク Markdown の絶対パスをクリップボードへコピーできるようにする。

## 完了条件

- タスク行右クリックメニューに「パスのコピー」が追加されている
- 詳細ペイン下部の登録日時・ID表示部分を右クリックすると「パスのコピー」が表示される
- main process が `taskId` から現在の実ファイルパスを解決し、renderer は保存済みパスを直接扱わない
- コピー成功・失敗がユーザーに通知される
- `npm run build` が成功する

## 実施結果

- `shell:copyTaskFilePath` IPC を追加し、main process が `taskId` から実ファイルパスを解決してクリップボードへコピーするようにした。
- タスク行右クリックメニューに「パスのコピー」を追加した。
- 詳細ペイン下部フッターの右クリックメニューに「パスのコピー」を追加した。
- コピー成功・失敗を画面上に通知するようにした。
- Node 22.14.0 環境で `npm run build` が成功した。
