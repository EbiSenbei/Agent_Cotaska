## 目的

詳細ペイン拡大中に、左サイドバーの「リスト」アイコンまたは「検索」アイコンを押すと通常表示へ戻るようにする。

## 完了条件

- `activeIcon` が「リスト」へ切り替わる。
- `activeIcon` が「検索」へ切り替わり、検索画面へ移行する。
- `detailPaneExpanded` が `false` になり、ナビパネル・メインペインが再表示される。
- 設定アイコンの既存挙動を変えない。
- production build が成功する。

## 実施メモ

- `App.jsx` にサイドバーアイコンクリック用ハンドラを追加した。
- 「リスト」アイコン押下時は `activeIcon` を「リスト」へ切り替えたうえで `detailPaneExpanded` を `false` にする。
- 追加対応として、「検索」アイコン押下時も `activeIcon` を「検索」へ切り替えたうえで `detailPaneExpanded` を `false` にする。
- 設定アイコンは従来どおり `activeIcon` の切り替えのみ行う。
- 拡大中の詳細ペインがサイドバーより前面に出てクリックを奪っていたため、サイドバーを詳細ペインより前面に表示するようにした。
- サイドバーアイコンを `button` 要素に変更し、クリックターゲットを明確化した。
- 通常の拡大ボタン操作を阻害しないよう、拡大解除はサイドバーアイコン押下時のハンドラだけで行う。
- 同梱 Node.js 22.14.0 で `npm run build` 成功。
