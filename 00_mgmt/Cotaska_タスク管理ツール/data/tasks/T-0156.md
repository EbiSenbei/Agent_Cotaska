## 作業内容

CotaskaにCodex SDKを使ったAIチャット連携基盤を実装する。

CHG-058の対象はCodex SDKのみとし、複数AI CLIプロバイダ方式は対象外とする。

## 実装方針

- main processにAIデータ保存サービスとCodex SDK実行サービスを追加する。
- AIスレッド、チャット履歴、参照ファイル、実行ログ、タスク更新提案を `data/ai.sqlite` に保存する。
- preloadに `cotaskaAPI.aiChat` 名前空間を追加する。
- rendererにAI作業画面を追加し、スレッド/ファイル切替、チャット、タスク/ファイル/差分ビューを表示する。
- 設定画面にCodex SDK作業フォルダ、AIデータ保持日数、参照ファイル上限、古いAIデータ削除操作を追加する。
- Codex SDK実行は初期権限 `read_only` を基本とし、タスク・ファイル変更は提案として保存する。
- タスク更新提案は `update_task` / `create_task` / `update_file` を許可し、承認後のみCotaska側で反映する。

- [x] `sql.js` と `@openai/codex-sdk` が追加されている。
- [x] `data/ai.sqlite` を初期化し、AI関連テーブルを作成できる。
- [x] `cotaskaAPI.aiChat` 経由でAIスレッド、メッセージ、参照、提案、実行ログを操作できる。
