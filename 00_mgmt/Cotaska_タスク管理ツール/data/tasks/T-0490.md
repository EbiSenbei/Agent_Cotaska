方針:
- 外部から利用される`taskService` APIは維持する。
- 内部処理を小さなモジュールへ段階的に移す。
- 先に既存動作を固定するテストを追加する。

完了条件:
- 各モジュールの責務と依存方向が明確になる。
- タスク作成、更新、親子連動、並び替え、ファイル監視との連携に回帰がない。

## 実施結果

- 階層深度、親変更検証、子孫収集、親状態推定を `src/main/taskHierarchy.js` へ分離した。
- main process の純粋関数テストを追加し、Vitest の対象を renderer と main の双方へ拡張した。
- `npm test`（5件）と `npm run build` の成功を確認した。
