CHG-092 の実装タスク。

## 目的

AIチャット上の Markdown リンククリック時に、ローカルファイルを添付ファイルクリック時と同じ右サイドパネルへ表示する。

## 実装内容

- main process に、リンク先を開かずに解決結果を返す IPC を追加または既存IPCを拡張する。
- `file://`、相対パス、URLエンコード、行番号付きリンクを正規化する。
- `AiChatPane` の `handleOpenMarkdownLink` で、ローカルファイルは `openFileContext` へ渡す。
- タスクファイルは既存のタスク詳細表示、テキスト/Markdown/PDFは既存のプレビュー表示を再利用する。
- 外部URLは従来どおり既定ブラウザで開く。

## 完了条件

- AIチャット本文のローカルファイルリンククリックで右サイドパネルが開く。
- 右サイドパネル内Markdownプレビューのリンククリックでも同じ挙動になる。
- 存在しないファイルや未対応形式では、画面を白画面化させず右サイドパネルまたは通知でエラーを示す。
- 既存の添付ファイルクリック挙動に回帰がない。

## 実施結果

- `aiChat:resolveLinkTarget` IPC を追加し、ローカルファイルは既存 `openFileContext`、外部URLは既定ブラウザへ振り分けるよう実装した。
- 存在しないファイル・フォルダ・未解決リンクは右サイドパネルにエラーを表示し、メイン画面を遷移させない。

## 検証結果

- `npm run build` を実行し、Vite の本番ビルドが成功した。
