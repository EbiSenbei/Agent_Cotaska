## 目的

設定画面の「Claude Code認証」で、パッケージ版の `app.asar` 内にある Claude Agent SDK の `claude.exe` を起動しようとして失敗する問題を解消する。

## 作業内容

1. `20_app/package.json` の Electron Builder 設定で、Claude Agent SDK のプラットフォーム別パッケージを `asarUnpack` の対象に追加する。
2. パッケージ後に `claude.exe` が `resources/app.asar.unpacked/node_modules/@anthropic-ai/claude-agent-sdk-win32-x64/` に存在することを確認する。
3. 設定画面のClaude Code認証確認で native binary 起動エラーが表示されないことを確認する。
4. ローカル認証とBedrock認証の認証結果が画面に表示されることを確認する。

## 完了条件

- Windows x64 のパッケージ版で Claude Code native binary を正常に起動できる。
- Claude Code認証確認時に native binary 起動エラーが発生しない。
- Codex連携および既存ビルドに回帰がない。
