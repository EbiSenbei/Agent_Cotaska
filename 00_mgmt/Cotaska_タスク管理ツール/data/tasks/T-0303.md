## 目的

ユーザー確認済みの画面モックに基づき、タスク詳細ペイン右側の「▽メタ情報」へ期限項目を追加する。

## 実装方針

- 期限の保存値は既存の `due_date` を利用する。
- 新規 frontmatter フィールドは追加しない方針を基本とする。
- 既存の日付変更 UI とタスク更新経路を再利用できるか確認する。

## 完了条件

- 詳細ペインのメタ情報で「日付」と「優先度」の間に「期限」が表示される。
- 期限あり・期限なしの表示が仕様どおりになる。
- 期限編集時に `due_date` が正しく保存・再表示される。
- 優先度表示や既存の日付変更 UI に回帰がない。

## 実施結果

- `20_app/src/renderer/components/DetailPane.jsx` のメタ情報1行目へ「期限」を追加した。
- 「日付」「期限」はどちらも既存 `due_date` を表示し、クリック時は既存の `DueDatePopover` を開く。
- `20_app/src/renderer/App.css` で日付・期限の間隔を詰めた。
- 同梱 Node v24.14.0 で Vite build を実行し、ビルド成功を確認した。
