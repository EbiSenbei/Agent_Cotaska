## 目的

Codex SDKの `agent_message` 更新を、処理中カードだけでなくチャット本文として逐次表示し、体感速度を改善する。

## 背景

T-0359では、Cotaskaは途中イベントを処理中カードへ表示している一方、assistant本文は完了後に反映されるため、Codex直接利用より遅く感じやすいと整理した。

## 関連タスク

- T-0327: Codex SDKチャットのストリーミング表示に対応する
- T-0350: 処理中のチャット表示の初期実装

本タスクでは、T-0359の速度改善観点として、`agent_message` 本文の逐次表示に絞って扱う。

## 対応内容

- renderer側で一時assistantメッセージを作成する。
- `agent_message` の `item.text` を受信したら、一時assistantメッセージ本文を更新する。
- 完了時はDB保存済みの最終assistantメッセージへ差し替える。
- 中断・エラー時に一時メッセージが残り続けないようにする。
- 自動スクロールや「一番下へ」ボタンと矛盾しないようにする。

## 完了条件

- AI応答生成中に、チャット本文が逐次更新される。
- 完了後は保存済みの最終応答と表示が一致する。
- 中断・エラー時もUIが破綻しない。
- 体感速度改善の確認結果が記録されている。

## 対応結果

`agent_message` の途中本文をチャット欄へ逐次表示するため、renderer側のAIチャット表示を修正した。

変更対象:

- `20_app/src/renderer/components/AiChatPane.jsx`
- `20_app/src/renderer/App.css`

変更内容:

- Codex SDKのrun eventから `agent_message` の `item.text` を抽出する処理を追加。
- 送信ごとに一時assistantメッセージIDを作成。
- `agent_message` の本文を受信したら、一時assistantメッセージを追加または更新する。
- 完了時は、従来どおりDB保存済みの正式なassistantメッセージへ差し替える。
- エラー時は、一時assistantメッセージを取り除いてエラーメッセージへ差し替える。
- 中断時は、一時assistantメッセージを取り除いて中断要求メッセージを表示する。
- 処理中カード側の `agent_message` は、本文全文を重複表示しないように「応答本文を受信しています」というイベント表示にした。
- 一時assistantメッセージには `ai-message--streaming` を付与し、生成中であることが分かる軽い表示を追加した。

## 検証

- 同梱Node.js v24.14.0で `npm run build` 成功。

## 確認待ち

- 完了後に、DB保存済みの最終応答へ差し替わることを確認する。
- 中断時に一時assistantメッセージが残らないことを確認する。
