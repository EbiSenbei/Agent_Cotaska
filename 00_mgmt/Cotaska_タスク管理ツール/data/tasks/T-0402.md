AIチャットの実行管理を画面遷移で破棄されない単位へ整理し、別画面へ移動しても処理が継続するように実装する。

## 完了条件

- AIチャット画面から離れても実行中のAI処理が継続する。
- AIチャット画面へ戻ったときに実行中状態、短期保存された途中経過、または完了結果が表示される。
- 処理中スレッドの右端にアニメーションする処理中アイコンが表示され、実行終了後に消える。
- 明示的な中断操作では従来どおり対象の実行へキャンセル要求が送られる。
- ビルドまたは該当範囲の検証が成功している。

## 実施結果

- main process の `codexSdkService` にアクティブAI実行一覧と途中イベント短期キャッシュを追加。
- `aiChat:listActiveRuns` / `aiChat:listRunEvents` IPC と preload bridge を追加。
- AIチャット画面でアクティブ実行を定期同期し、画面復帰・スレッド再選択時に処理中表示と短期保存済み途中イベントを復元するように実装。
- スレッド一覧で処理中スレッド行の右端にアニメーションスピナーを表示。
- `npm run build` と main process 対象ファイルの `node --check` に成功。
