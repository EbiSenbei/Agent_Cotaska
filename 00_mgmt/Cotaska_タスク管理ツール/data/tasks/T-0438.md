Codex / Claude Code（ローカル・Bedrock）で AI チャットが正しく動作し、配布版でローカル認証が無効化されることを確認する。

- 設定画面で連携先（Codex / Claude Code）と、Claude の認証方式（ローカル / クラウドプロバイダBedrock）を切り替えられる。
- Claude（ローカル認証）で、ローカルの Claude Code 認証でチャット（送信・逐次表示・最終応答・キャンセル）が動作する。
- Claude（Bedrock）で、AWS資格情報 + CLAUDE_CODE_USE_BEDROCK=1 によりチャットが動作する。
- Codex 選択時に従来どおり動作する（デグレなし）。
- provider 未設定/不正値で "codex"、claudeAuthMode 未設定/不正値で "local" にフォールバックする。
- Claude 未認証時（ローカル）に checkAuthStatus が要ログインを返す。Bedrock 資格情報不備時に適切なエラーを返す。
- 配布ビルドでローカルサブスク認証が選択できず、Bedrock モードのみ選択できる。AWS資格情報が平文保存されない。
