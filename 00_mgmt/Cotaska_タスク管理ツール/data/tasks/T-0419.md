AIモードでタスクチャットを利用後、リストモードを経由してAIモードへ戻ると、利用者が作成していない同名AIスレッドが増える不具合を調査・修正する。

## 調査観点

- AI画面再表示時のタスクチャット要求が重複実行されていないか確認する。
- 同一 `primary_task_id` の未アーカイブAIスレッド検索・再利用が正しく動作するか確認する。
- AIスレッドDBの重複レコードと画面表示の重複のどちらで発生しているか確認する。

## 完了条件

- モード移動・AIモード再表示だけでAIスレッドが新規作成されない。
- 利用者が明示的に新規スレッドを作成した場合は従来どおり追加できる。
- 修正後の動作確認結果をバグレポートへ記録する。

## 実施結果

- AIモード再表示時に残っていた同一タスクチャット要求が再実行されること、main processがそのたびに新規スレッドを作成していたことを原因として特定した。
- rendererで処理済み要求を消費し、main processでは同一タスクの未アーカイブスレッドを再利用するよう修正した。
- 構文チェックと `npm run build` は成功した。実アプリでのモード往復確認はユーザー確認待ち。
