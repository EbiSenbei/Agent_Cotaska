AIチャット上の Markdown リンクをクリックすると、Cotaska のメイン画面が白画面になる不具合。

## 調査結果

- `00_mgmt/Cotaska_タスク管理ツール/logs/app-2026-07-09.log` に `Renderer load failed: code=-6, desc=ERR_FILE_NOT_FOUND` が出ていた。
- メインウィンドウが `file://...md:1` へ直接遷移しており、Electron がその URL の読み込みに失敗していた。
- 実行中のアプリは `version: 0.2.8` だった。
- 配置済み `app.asar` には、AIチャット Markdown リンク処理とメインウィンドウの外部遷移ガードが含まれていなかった。
- 現行ソースには、リンクを外部アプリで開き、アプリ外遷移をブロックする対策が含まれている。
- 0.2.9 への Portable 更新は、BUG-20260710-01 のパス長問題で失敗していた。

## 対応内容

- BUG-20260710-02 として不具合対応レポートを作成。
- 現行ソースに含まれるリンク処理・遷移ガードが今回の現象への対策になっていることを確認。
- BUG-20260710-01 の更新失敗対策を反映後、0.2.9 を実行環境へ適用して再確認する。

## 検証

- 配置済み 0.2.8 の `app.asar` に対策コードが含まれていないことを確認。
- 現行ソースに対策コードが含まれていることを確認。

## 状態

対策済みビルドの実行環境反映と、AIチャットリンククリックのユーザー確認待ち。
