Cloudflare R2公開時に`Get-CotaskaGitCommit`がWindows PowerShell 5.1で実行エラーになる問題を修正する。

## 完了条件

- Windows PowerShell 5.1でGitコミットIDの取得に成功する
- Git情報を取得できない場合は`unknown`へフォールバックする
- v0.3.5のリリース生成と共通成果物検証が成功する
- R2の`latest/`へZIP、SHA-256、version.jsonを公開できる
- ユーザー確認後に完了する

## 実施結果

- `return if (...)`を、Git成功時と失敗時の明示的なreturnへ変更した。
- Windows PowerShell 5.1で構文エラー0件、GitコミットID取得成功、Git情報なし時の`unknown`フォールバックを確認した。
- 修正コミット`f5770c0`からv0.3.5を再生成し、全出荷チェックと共通成果物検証が成功した。
- Cloudflare R2のZIP、SHA-256、version.jsonを公開し、HTTP 200を確認した。
- 公開versionは`0.3.5`、公開Gitコミットは`f5770c025992ce1451b8e5fa483a7ee00abfc13f`である。
- 公開SHA-256とローカルZIPのSHA-256が`acbc234ad441f6a70178992cf43d0a4b3524a7774aa15930c03e47d86ca4b9fb`で一致した。

## ユーザー確認事項

- Cotaskaの設定画面から更新確認を行い、v0.3.5を検出できることを確認する。
- 必要に応じて更新ダウンロードと再起動後のバージョン表示を確認する。
