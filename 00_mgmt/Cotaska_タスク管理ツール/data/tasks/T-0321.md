## 目的

子タスクの進捗ステータスを保留に変更したとき、親タスクまで連動して保留になってしまう不具合を修正する。

## 現象

子タスクを保留にすると、親タスクの進捗ステータスも保留へ変わってしまう。

ユーザー要望として、子タスクの保留はその子タスク単体の状態として扱い、親タスクには連動させない。

## 完了条件

- 子タスクを保留にしても、親タスクの進捗ステータスが変更されない。
- 親タスクを保留にする操作が必要な場合は、親タスク自身を明示的に更新したときだけ反映される。
- 親子タスクの完了連動や進捗表示に既存の退行がないことを確認する。
- バグレポート BUG-20260627-02 に調査結果と修正結果が記録されている。

## 実施メモ

- 子タスク状態から親タスクを再推定する処理で、`保留` を親へ伝播しないようにした。
- `仕掛` / `完了` の子タスクがある場合だけ、未着の親タスクを `仕掛` へ自動開始する挙動は維持した。
- 親タスクを明示的に保留へ変更した場合に、未完了の子孫を保留へ同期する既存挙動は維持した。
- 同梱 Node.js 22.14.0 で `npm run build` 成功。
