## 目的

単純な一般質問でも参照ファイルが常にプロンプトへ展開される状態を見直し、不要な入力増加を抑える。

## 背景

T-0359では、参照ファイルが付いているスレッドで時刻質問を行った場合にも、参照ファイルがプロンプトに展開される可能性があると整理した。
今回の `T-0079.md` は小さいが、実運用では大きな参照ファイルが付く可能性がある。

## 対応内容

- 現在の `buildReferenceContext()` の利用条件を確認する。
- 参照ファイル送信モードを追加する。
  - 常に送信
  - 明示時のみ送信
  - 速度優先時は送信しない
- 初期値は既存挙動を壊さない方針にする。
- AIチャット入力欄または設定画面で、参照ファイルを送る/送らない状態が分かるようにする。
- 送信時ログに、参照ファイルを送ったかどうかを記録する。

## 完了条件

- 単純質問で参照ファイルを送らない選択ができる。
- 参照ファイルを送る必要がある質問では、従来どおり送信できる。
- 応答速度比較が記録されている。

## 対応メモ

- ソースコード確認の結果、対応前は `buildReferenceContext()` が参照ファイルを常に展開していたため未実装と判断。
- `aiChat.referenceSendMode` 設定を追加し、`always` / `manual` / `skip-in-speed` を選べるようにした。
- AIチャット入力欄に一時指定として `参照:設定` / `参照:送る` / `参照:送らない` を追加。
- `buildReferenceContext()` で参照送信モードを判定し、送らない場合は参照ファイル本文を読み込まずプロンプトへ展開しないようにした。
- 診断ログに `reference_send_mode`、`reference_sent`、`reference_skipped_reason` を追加。
- `npm run build` でビルド成功を確認。
