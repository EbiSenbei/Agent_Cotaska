AIモードでチャット欄に「↓」アイコンが表示されているが
クリックしても一番下にスクロールされない。
クリックしたら一番下にスクロールされるようにしてほしい

## 対応結果

- 「↓」ボタンの `onClick` でスクロール関数を直接渡していたため、クリックイベントオブジェクトがスクロール挙動の引数として渡る可能性があった。
- `onClick={() => scrollMessagesToBottom()}` に変更し、クリック時に明示的に一番下へスクロールするようにした。
- `scrollMessagesToBottom` 側でも、`behavior` が文字列でない場合は `smooth` に補正するようにした。
- 対応記録: `10_docs/30_変更管理/20_バグレポート/20260630_01_AIチャット下スクロールボタンが効かない.md`

## 検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。
