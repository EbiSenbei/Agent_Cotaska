ファイルツリーからドラッグして添付ファイルにできるようにしてほしい

## 対応結果

- フォルダツリーのファイル行をドラッグ可能にした。
- チャット投稿ボックスへファイルをドロップすると、AIスレッドの参照ファイルとして追加されるようにした。
- ドロップ可能な状態では、投稿ボックスを青くハイライトして分かるようにした。
- フォルダ行はドラッグ対象にせず、従来どおり展開/折りたたみ操作とした。
- 既に添付済みのファイルをドロップした場合は、既存の重複チェックにより追加済みメッセージを表示する。

## 検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。
