## 目的

renderer から main process へ Codex 認証状態確認を依頼できるIPCを追加する。

## 対応内容

- `window.cotaskaAPI.aiChat` または設定系APIに認証診断用メソッドを追加する。
- main process 側でT-0354の調査結果に基づく診断処理を実装する。
- 戻り値は `available` / `login_required` / `expired_possible` / `sdk_missing` / `error` など、UIが扱いやすい区分にする。
- 診断結果には秘密情報、アクセストークン、APIキー、認証ファイル内容を含めない。
- 診断失敗時はユーザーに表示可能な安全なエラーメッセージへ整形する。

- [x] 診断結果に秘密情報が含まれない。
