AI処理途中イベントが追加されたとき、チャット表示を自動で下へ追従させる。

## 完了条件

- `streamEvents` 更新時にスクロール予約が処理される。
- 通常メッセージ追加時の既存挙動を壊さない。
- 構文検証またはビルドが通る。

## 実施結果

- `AiChatPane.jsx` のスクロール処理 effect の依存配列に `streamEvents` を追加した。
- 処理途中イベント追加時に `requestScrollMessagesToBottom()` が立てた予約を、`streamEvents` 更新後の描画フレームで処理できるようにした。
- `npm run build` は Node.js 20.18.1 が Vite 8 の要件 20.19+ を満たさず失敗したため、環境要因として記録する。
