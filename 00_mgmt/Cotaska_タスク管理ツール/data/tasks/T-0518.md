T-0516の設計に従い、ごみ箱確認とAIスレッド名変更modalへ共通のEnter / Exitを追加する。

## 実装範囲

- `App.jsx`のごみ箱確認modal
- `AiChatPane.jsx`のAIスレッド名変更modal
- `app-components.css`の共通overlay / dialog入退場スタイル
- キャンセル、背景クリック、確定操作、既存のEscape操作を含む全close経路のExit lifecycle
- Exit中の二重操作防止とmodal semanticsの維持
- Reduced motion時のopacity-only表現

## 完了条件

- overlayとdialogが中央基準で静かに出入りし、表示・非表示が瞬間的に切り替わらない
- close経路によらず同じExitを通り、完了後にunmountされる
- Exit中の再操作や連続open / closeで二重処理、focus喪失、表示残留が起きない
- dialog role、フォーカス、キーボード操作、背景操作の既存挙動を損なわない
- Reduced motion、関連テスト、本番ビルドが成功する

## 実施結果

- ごみ箱確認とAIスレッド名変更へ共通`useExitPresence` lifecycleを適用した
- overlayのopacityと中央原点dialogの`opacity + scale(.97)`で、Enter 160ms、Exit 120msを実装した
- キャンセル、背景クリック、Escape、削除確定、名前変更確定の全経路を同じExitへ揃えた
- Exit中はoverlayのpointer eventを無効化し、inputとbuttonをdisabledにして二重操作を防止した
- AIスレッド名変更へ`role="dialog"`、`aria-modal="true"`、見出しlabelを追加し、ごみ箱確認の既存dialog semanticsも維持した
- Exit中の再openはfallbackを解除し、同じDOMを現在値からSettledへretargetする
- Reduced motionではscaleを外し、120msのopacity-only transitionにした
- Node.js 22.14.0でVitest 7件と本番ビルドが成功した
