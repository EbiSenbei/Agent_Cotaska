## 目的

起動後に更新確認を実行し、更新ありの場合のみアプリ上部に通知アイコンを表示する。

## 完了条件

- 初回ロード完了後に `updates.check()` が1回だけ呼ばれる
- `hasUpdate` が true の場合、左端サイドバー上部に通知アイコンが表示される
- 通知アイコン押下で設定画面へ移動できる
- 更新なし、未対応環境、確認失敗では通常操作を妨げない
- `npm run build` が成功する
