T-0544 および `10_docs/30_変更管理/20_バグレポート/20260730_01_起動時に表示名が反映されない.md` を正本として、起動時に保存済みの表示名が画面ヘッダへ反映されない原因を調査し、修正する。

完了条件:

- 保存済みの表示名を持つ状態で Cotaska を再起動しても、起動直後から画面ヘッダに表示名が反映される。
- 設定画面を開いて保存する操作なしで再現しないことを確認する。
- 修正後の検証結果をバグレポートへ追記し、ユーザー確認待ちへ更新する。

調査結果（2026-07-30）:

- `BrowserWindow` 作成時のタイトル設定は、renderer の `dist/renderer/index.html` にある固定 `<title>Cotaska</title>` によりページ読込時に上書きされる。
- 設定保存時はページ読込後に `mainWindow.setTitle()` を呼ぶため、保存操作後だけ表示名が反映される。

実装・検証結果（2026-07-30）:

- `src/main/main.js` の `did-finish-load` 後に保存済み表示名を再設定する修正を実装した。
- `node --check src/main/main.js` と `npm test`（4ファイル・9テスト）は成功した。
- Node.js 20.18.1 のため `npm run build` はプロジェクトのNode.js 22系要件チェックで停止した。実アプリ再起動時の画面ヘッダはユーザー確認待ちとする。

ユーザー確認結果（2026-07-30）:

- ユーザーによる動作確認OK。完了とする。
