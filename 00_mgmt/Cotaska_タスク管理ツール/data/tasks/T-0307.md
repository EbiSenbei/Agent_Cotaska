## 目的

`DueDatePopover` の「今日」「明日」「1週間後」「日付のみ」ショートカット押下時に、選択結果反映だけでなく `onChange` を呼び出して即時保存する。

## 完了条件

- 「今日」「明日」「1週間後」「日付のみ」が即時保存される。
- カレンダー選択、時刻設定、クリア、OK の既存操作に回帰がない。
- ビルドが成功する。

## 実施結果

- `DueDatePopover.jsx` の `今日` / `明日` / `1週間後` / `日付のみ` ショートカット押下時に `onChange` を呼び出し、OK 相当で即時保存するようにした。
- 同梱 Node v24.14.0 で Vite build を実行し、成功を確認した。
