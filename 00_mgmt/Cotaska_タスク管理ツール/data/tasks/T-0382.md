CHG-090 の実装タスク。

## 対応内容

- `settingsService` の `DEFAULT_SETTINGS.aiChat.workdir` を空欄にする。
- `settings.yaml` に `aiChat.workdir` が存在しない場合も空欄として扱う。
- 旧自動生成値である `_app/resources` 配下の作業フォルダは空欄へ移行する。

## 完了条件

- 新規設定ファイルの作業フォルダが空欄になる。
- 既存の `_app/resources` 自動生成値が空欄として扱われる。
- ビルドが成功する。

## 実施結果

- `DEFAULT_SETTINGS.aiChat.workdir` を空欄へ変更した。
- `_app/resources` 配下の旧自動生成値を未設定として正規化する処理を追加した。
- AI実行時に作業フォルダ未設定の場合、別パスへフォールバックせず未設定エラーにするよう変更した。
- `npm run build`、`release-all.ps1`、`sync-task-master-release.ps1` が成功した。
