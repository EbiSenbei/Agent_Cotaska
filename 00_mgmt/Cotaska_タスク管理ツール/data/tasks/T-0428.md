設定画面のAI参照上限に表示される送信方法の選択肢、補足説明、アクセシブルな名称を日本語化する。

## 対応結果

- `always` を「常に送信」へ変更した。
- `manual` を「手動指定時のみ送信」へ変更した。
- `skip-in-speed` を「高速モードでは送信しない」へ変更した。
- 選択肢の値は既存値のままとし、保存済み設定との互換性を維持した。
- Node.js 22.14.0で `npm run build` を実行し、Vite本番ビルドが成功した。
