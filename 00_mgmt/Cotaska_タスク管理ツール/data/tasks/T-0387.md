CHG-091 の実装タスク。

## 実装内容

- AIチャットの処理途中イベントを上書き表示ではなく配列として保持し、時系列で表示する。
- 処理途中イベントが追加されたとき、表示領域内で自然に下方向へ増えるようにする。
- 最終回答を受信したら、処理途中イベントをクリアして最終回答メッセージを表示する。
- エラー時・キャンセル時は設計方針に従って、途中経過とエラー/中断状態の表示を制御する。

## 完了条件

- 処理中イベントが複数件表示される。
- 最終回答表示時に処理中イベントが残らない。
- 既存のチャット履歴、コピー、リンククリック、キャンセル処理に悪影響がない。
- ビルドが成功する。

## 実施結果

- `20_app/src/renderer/components/AiChatPane.jsx` の処理途中イベントを、同一IDマージではなく表示用IDを付けて追記する方式へ変更した。
- `agent_message` の途中本文を一時 assistant メッセージとして上書き表示せず、処理途中イベントとして下方向へ累積表示するよう変更した。
- 最終回答受信時と終了時に `streamEvents` をクリアする既存処理により、途中経過は最終回答表示後に残らない。
- エラー時・キャンセル時は既存のエラー/中断メッセージへ置換し、処理途中イベントは終了時にクリアされる。

- 同梱 Node.js v24.14.0 で `npm run build` 成功。
- `20_app/release-all.ps1` 成功。
- `20_app/sync-task-master-release.ps1` 成功。
