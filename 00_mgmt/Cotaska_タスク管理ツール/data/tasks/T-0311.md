## 対応記録

- 2026-06-25: `BUG-20260625-02` としてバグレポートを起票し、原因調査を開始。
- 2026-06-25: 原因調査。完了ビューでも進捗セクション化が有効になり、`MainPane.jsx` の `renderFlatList()` 内にある「次を読み込む」ボタンが描画されないことを確認。main 側の `tasks:getCompletedPage` と `hasMore` 算出は存在するため、主因は renderer の表示分岐。
- 2026-06-25: `App.jsx` の `useProgressSections` 条件から完了ビューを除外して修正。Codex 同梱 Node.js `v24.14.0` で `npm run build` 成功。
