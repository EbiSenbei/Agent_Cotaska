CodexとClaude Codeの設定欄に「既定のAIモデル」選択を追加する。自動は空文字として保存し、実行時の既存既定モデル解決へ委ねる。既存の任意モデルIDは互換選択肢として表示し、設定値を失わないようにする。

## 完了条件

- [x] Codexで自動、GPT-5.6 Terra、GPT-5.6 solを選択できる。
- [x] Claude Codeで自動、Claude Opus 4を選択できる。
- [x] AIチャット画面にモデル選択UIを追加しない。

## 実施結果

- Codexの自動選択肢は `自動（現在: GPT-5.6 Terra）` と表示し、空文字の設定値が `gpt-5.6-terra` へ解決されることを利用者が把握できるようにした。
