codexSdkService.js を雛形に、同一シグネチャの claudeCodeService.js を新設し、provider 切替と Claude 認証2系統を実装する。

- `@anthropic-ai/claude-agent-sdk` の `query({ prompt, options })` を async iterable で回し、emitRunEvent で UI へ流す。
- 認証モード分岐:
  - local … ローカルの Claude Code 認証（~/.claude/）を利用。
  - bedrock … SDK 起動時に `CLAUDE_CODE_USE_BEDROCK=1` + AWS 資格情報 + モデルID を環境変数注入。
  - ※ Bedrock の正確な環境変数名・対応モデルID・渡し方は実装時に最新ドキュメントで確認。
- main.js の aiChat:* 5ハンドラを aiProviderRegistry 経由のディスパッチへ変更。
- SettingsPane.jsx に「連携先」セレクト（Codex / Claude Code）と、Claude 選択時の「認証方式」セレクト（ローカル / クラウドプロバイダBedrock）＋Bedrock 用入力欄を追加。
- settingsService.js に `aiChat.provider` / `aiChat.claudeAuthMode` / Bedrock 用項目を追加（正規化・YAML出力対応）。AWS資格情報は平文保存しない。
- 配布ビルドではローカルサブスク認証を無効化/非表示にし、Bedrock モードのみ選択可能にする。
