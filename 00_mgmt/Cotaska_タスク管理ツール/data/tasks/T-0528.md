`npm run build` がNode.js v20.18.1で停止したため、プロジェクト要件であるNode.js 22.14.0以上の22系へ開発環境を切り替える。

切替後に `20_app` で `npm run build` を実行し、CHG-117のタスク詳細別ウィンドウを含むrendererビルドが成功することを確認する。

## 実施結果

- Node.js v22.14.0 / npm 10.9.2 で依存関係を復元した。
- `release-all.ps1 -Version 0.3.5` 内の `npm run build` が成功した。
- rendererは113モジュールを変換し、Electronパッケージング、ランチャー、アップデーター、出荷前検証、ZIP作成まで正常完了した。
- 検証済み成果物をタスク正本へ同期し、主要3ファイルのSHA-256一致を確認した。
