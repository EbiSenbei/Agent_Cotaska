## 仕様変更概要

CotaskaにCodex SDKを使ったAIチャット連携機能を追加する。

CHG-058の対象はCodex SDKのみとし、GitHub Copilot CLI、Claude Code、Gemini CLIなどの複数AI CLIプロバイダ方式は対象外とする。

Cotaskaの画面から相談内容を入力し、Electron main processからCodex SDKを呼び出して応答を取得する。AIスレッド、チャット履歴、参照ファイル、Codex SDK側threadId、実行ログ、タスク更新提案、承認/却下履歴は `data/ai.sqlite` に保存する。

タスクやファイルへの反映は、Codex SDKの自然文を直接適用せず、Cotaskaが検証できる構造化アクションとして扱う。ユーザーがプレビューを確認して承認した場合のみ、既存の `taskService` または作業フォルダ内ファイル更新として反映する。

## 対象連携方式

- Codex SDKのみ

## 段階実装方針

1. Codex SDK連携、AIデータ保存、AI画面構成を設計へ反映する。
2. Electron main processにCodex SDK実行基盤とSQLite保存基盤を実装する。
3. rendererにAI作業画面を追加する。
4. タスク/ファイル反映用の構造化アクションと承認制を実装する。
5. ユーザー確認で認証、チャット表示、承認制反映を確認する。

## 方針

- Cotaska内にOpenAI APIキーやCodex access tokenを保存しない。
- rendererはCodex SDKを直接呼び出さず、`window.cotaskaAPI.aiChat` からmain processへ依頼する。
- Codex SDK実行権限は初期値 `read_only` とし、ファイルやタスクへの直接反映はCotaska側の承認制アクションで行う。
- AI応答はチャット表示用メッセージとタスク/ファイル反映用アクションに分ける。
- タスク反映は必ずユーザー承認制にする。
- `_index.yaml` は生成物として扱い、タスク本体は `data/tasks/*.md` を正とする。
