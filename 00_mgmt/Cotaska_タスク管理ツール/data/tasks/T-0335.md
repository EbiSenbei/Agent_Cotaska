画面左の「スレッド/ファイル」となっている
以前は「スレッド/フォルダ」となっていて、
「フォルダ」を選択したら、作業フォルダ配下のファイルツリーが見れるはずだった。
この仕様に戻してほしい

## 対応結果

- AI画面左ペインのタブ表示を `スレッド/ファイル` から `スレッド/フォルダ` に戻した。
- `フォルダ` タブでは、設定済みの作業フォルダ配下をファイルツリーとして表示するようにした。
- 作業フォルダツリー取得用の `aiChat:listWorkdirTree` IPC を追加した。
- ツリー表示では `node_modules`、`.git`、`dist`、`release` など重い/不要なフォルダを除外し、件数上限付きで表示する。
- ファイル行をクリックした場合、そのファイルをAIスレッドの参照ファイルとして追加できるようにした。
- 対応記録: `10_docs/30_変更管理/20_バグレポート/20260628_03_AI画面左ペインのフォルダタブがファイル表示になっている.md`

## 検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。

## 追加対応（2026-06-28）

ユーザー動作確認により、作業フォルダツリーの先頭表示が `D` / `F` 文字になっていること、フォルダを畳めないことを確認。

### 追加修正

- `D` / `F` 文字表示を廃止し、CSSでフォルダ/ファイルのアイコンを表示するようにした。
- フォルダ行に開閉用の矢印を表示するようにした。
- フォルダクリックで展開/折りたたみできるようにした。
- 初期表示はすべてのフォルダを畳んだ状態とし、ルート直下のみ表示するようにした。
- フォルダツリー更新時も展開状態をリセットし、初期折りたたみ状態へ戻す。

### 追加検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。

## 追加対応（2026-06-30）

ユーザー要望により、作業フォルダツリーのフォルダ/ファイルを右クリックしたときに操作メニューを出すようにした。

### 追加修正

- フォルダ/ファイル行の右クリックでコンテキストメニューを表示するようにした。
- メニューに `パスをコピー`、`エクスプローラで表示する`、`削除` を追加した。
- `パスをコピー` は対象の絶対パスをクリップボードへコピーする。
- `エクスプローラで表示する` は対象パスをエクスプローラで表示する。
- `削除` は確認ダイアログを出したうえで、作業フォルダ配下の対象だけを削除する。
- 削除後は作業フォルダツリーを再読み込みし、削除されたパスに紐づく参照ファイル表示も外す。
- すべてのファイル操作は設定済みの作業フォルダ配下に限定した。

### 追加検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。

## 追加対応（2026-06-28 その2）

ユーザー動作確認により、作業フォルダツリーに「表示件数が多いため一部を省略しています」と表示され、全件を確認できないことを確認。

### 追加修正

- 作業フォルダツリー取得時の件数上限を撤廃した。
- ツリー表示領域をスクロール可能にし、VSCodeのエクスプローラーのように縦スクロールで全体を確認できるようにした。
- 長いパスや深い階層でも確認しやすいよう、ツリー行は必要に応じて横方向にもスクロールできる幅にした。
- 初期表示は引き続き全フォルダを畳んだ状態とする。

### 追加検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。
