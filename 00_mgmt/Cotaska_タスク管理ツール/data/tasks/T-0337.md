チャット投稿直後は、チャット欄の一番下に自動で移動してほしい

## 対応結果

- AIチャット投稿時に、自動スクロール予約を立てる処理を追加した。
- 投稿直後のユーザーメッセージ表示時に、チャット欄の一番下へ移動するようにした。
- Codex SDK応答反映時、または送信エラー表示時にも一番下へ移動するようにした。
- 通常の閲覧・手動スクロール中は既存の「↓」ボタン表示制御を維持する。

## 検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。
