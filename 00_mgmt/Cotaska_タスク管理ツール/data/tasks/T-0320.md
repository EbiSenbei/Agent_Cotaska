## 目的

CHG-088 のメイン一覧ドラッグ操作で、通常タスクを子タスクにする操作、および子タスクを親なしへ戻す操作が 2 回ドラッグしないと反映されない退行を修正する。

## 対応方針

- メイン一覧のドラッグ処理は HTML5 Drag & Drop に一本化し、独自ポインター方式を撤去する。
- 子タスクもドラッグ可能にする。
- 行中央は子タスク化、行上部/下部はドロップ先と同じ親階層への移動として保存する。
- 親なしタスクの行上部/下部へドロップした場合は `parent: null` に戻す。
- 「親なしに戻す」専用領域は撤去し、行上部/下部ドロップを主導線にする。

## 完了条件

- 1 回のドラッグで通常タスクを子タスク化できる。
- 1 回のドラッグで子タスクを親なしへ戻せる。
- 1 回のドラッグで別親の子タスク階層へ付け替えできる。
- Vite production build が成功している。
- バグレポート BUG-20260627-01 に修正結果が記録されている。

## 実施メモ

- 独自ポインター方式と「親なしに戻す」専用領域を撤去し、HTML5 Drag & Drop のみに整理した。
- `MainPane.jsx` で子タスクもドラッグ可能にし、行上部/下部/中央の位置から `before` / `after` / `child` を判定するようにした。
- `reorder` API の `field_updates` で `parent` と `list` を扱えるようにし、親子変更と並び替えを一括保存する経路へ寄せた。
- `App.jsx` のドラッグ保存処理から、子タスク化だけ別 `update` する経路を撤去し、行中央/上部/下部の親子変更を同じ `reorder` 呼び出しで処理するようにした。
- 行中央ドロップで子タスク化した場合、ドロップ先の親タスクを自動展開するようにした。
- Vite production build は成功済み。
