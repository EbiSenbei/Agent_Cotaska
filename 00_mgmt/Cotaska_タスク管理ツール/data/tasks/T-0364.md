## 目的

T-0359で追加したAIチャット詳細ログを有効化した状態で再計測し、Cotaska側の応答遅延がどこで発生しているかを切り分ける。

## 背景

Cotaska側では同じ時刻質問に約26.132秒、Codex直接利用では約5秒という差が出た。
ただし、ログ追加後にCotaskaを再起動していない可能性があり、`AI chat assistant response` の詳細ログが取得できていない。

## 対応内容

- Cotaskaを再起動し、最新のmain processでAIチャットを実行する。
- 同じ質問で再計測する。
- `logs/app-YYYY-MM-DD.log` の以下を確認する。
  - `AI chat request started`
  - `AI chat assistant response`
  - `timings_ms.total`
  - `timings_ms.open_ai_service_to_sdk_loaded`
  - `timings_ms.sdk_loaded_to_stream_started`
  - `timings_ms.stream_started_to_first_event`
  - `timings_ms.stream_started_to_first_agent_message`
  - `timings_ms.stream_started_to_completed`
- `data/ai.sqlite` の `ai_runs.started_at` / `finished_at` とも照合する。

## 完了条件

- Cotaska再起動後の詳細ログが取得できている。
- 遅延の主因候補を、SDK初期化、stream開始待ち、初回イベント待ち、応答生成待ちのどれかに分類できている。
- 調査結果をT-0359または本タスクへ追記している。

## 切り分け

今回の計測では、主な遅延は `new Codex()` やSDKロードではなく、Codex SDKのstream開始後に発生している。

- SDKロードまで: 約 `255ms`
- stream開始まで: 約 `61ms`
- 初回イベントまで: 約 `4.157秒`
- 初回agent_messageまで: 約 `14.050秒`
- 完了まで: 約 `15.225秒`

そのため、T-0359で疑っていた「毎回 `new Codex()` していること」が主因である可能性は低い。
ただし、今後の連続送信や大きなスレッドでは効果が変わる可能性があるため、T-0365で引き続き検討する。

一方、`input_tokens` が `29474`、`cached_input_tokens` が `24320` と大きい。
参照ファイルは0件、ユーザー入力は36文字にもかかわらず入力トークンが多いため、Codex SDK側が作業フォルダやスレッド/環境コンテキストを内部的に多く含めている可能性がある。

## 主因候補

現時点の主因候補は以下。

1. Codex SDK / Codex側の内部コンテキスト量が多い
   - 参照ファイルなしでも入力トークンが約29kある。
   - 作業フォルダ付きCodex実行として、環境やスレッド情報が含まれている可能性がある。

2. 初回agent_messageまでの待ち時間
   - 初回イベントは約4秒で来ているが、本文が出るまで約14秒かかっている。
   - 体感速度改善には、`agent_message` 以外の途中イベントをより見える化するか、本文逐次表示を強化する必要がある。

3. Codex直接利用とは計測範囲と内部条件が違う
   - Codex直接利用の5秒表示と、Cotaska SDK経由の15秒計測は完全に同じ条件ではない。
   - ただし、同じ質問で明確な差が残っている。

## 次の対応方針

優先度は以下。

1. T-0368: `agent_message` の途中本文表示を強化し、体感速度を改善する。
2. T-0367: 速度優先モード/Fast mode/軽量モデル指定の利用可否を確認する。
3. T-0366: 単純質問時の参照ファイル抑制に加え、作業フォルダ・内部コンテキスト量を減らす方法がないか確認する。
4. T-0365: SDKインスタンス使い回しは、今回の計測では主因ではなさそうだが、連続送信時の効果を確認する。

## 補足

今回はUI上のCotaska画面からではなく、最新の `codexSdkService.sendMessage()` を直接呼び出して再計測した。
ただし、`appLogger` と `data/ai.sqlite` へは通常経路と同じ形式で記録されている。
