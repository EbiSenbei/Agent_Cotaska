AIモードの左サイドパネルに検索欄があるが
「スレッド/フォルダ」の「フォルダ」を選択した時に
特に検索されない。

検索されるようにしてほしい

## 対応結果

- AI左サイドパネルの検索欄をstate管理に変更。
- スレッドタブでは、スレッドタイトル、サブタイトル、ID、バッジを検索対象にした。
- フォルダタブでは、ファイル/フォルダ名とパスを検索対象にした。
- フォルダ検索時は、該当ファイルだけでなく親フォルダも表示するようにした。
- 検索中はフォルダの折り畳み状態に関係なく検索結果を表示する。

## 検証

- 同梱Node.jsをPATH先頭にして `npm run build` 成功。
