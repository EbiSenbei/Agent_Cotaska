## 目的

最初の発信先をnoteとし、Cotaskaが誰に向けた何のツールか、具体的な使い方まで伝わる紹介記事を用意する。

## 前提・着手順

- 2026-10-26に利用者が了承した「note → SNS → Boothは後から判断」の最初の実作業。
- 主メッセージは「タスク管理とAIチャットを、ひとつの作業画面に。」。
- T-0294の完成動画・選定画像、T-0295の公開済みサイトと文案を使う。

## 作業

1. 仮題「タスク管理とAIチャットを、ひとつの作業画面に。Cotaskaを紹介します」で本文を作成する。
2. 困りごと → Cotaskaの紹介 → 複数タスク・子タスク・遅延／今日／完了の整理 → タスクからAIへ依頼 → 成果確認 → 導入案内の順でまとめる。
3. 開発背景は確認済みの事実を使い、利用者の体験や実績を創作しない。
4. 見出し画像と本文画像を選び、挿入位置・説明文・60秒動画への公式サイトリンクを付ける。
5. Windows 10 / 11 x64、本体無料・AI連携先の契約／利用料は別途という条件を明記する。通常配布はインストーラーとして案内する。
6. 末尾を公式サイト・初回登録手順・問い合わせへ統一し、利用者が確認できる原稿と素材一覧を保存する。
