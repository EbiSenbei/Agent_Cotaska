AIモードのチャット投稿ボタンが、AI処理中に「■」となるが、
この「■」をクリックされたら中断するようにしてほしい。

## 対応メモ

- Codex SDK の `run(input, { signal })` に `AbortSignal` を渡すように変更。
- Electron main process 側に実行中リクエストを管理する `request_id` と `AbortController` を追加。
- Renderer 側の送信ボタンは、送信中のみ「■」クリックで `aiChat.cancelRun(request_id)` を呼ぶように変更。
- 中断時は `ai_runs.run_status` を `canceled` とし、チャット上にも中断メッセージを表示する。
- 中断後に古い応答が遅れて返ってきても、現在の画面表示を上書きしないように `request_id` でガードする。

## 検証

- `node --check 20_app/src/main/codexSdkService.js`
- `node --check 20_app/src/main/main.js`
- `node --check 20_app/src/main/preload.js`
- 同梱 Node.js v24.14.0 で `npm run build` 成功。

## 確認待ち

- 実画面で AI 応答待ち中に「■」をクリックし、処理が中断されることを確認する。
