AI処理途中イベント追加時の自動スクロールを確認する。

## 完了条件

- ビルドまたは静的検証でエラーがない。
- `streamEvents` 更新がスクロール処理の依存に含まれていることを確認する。
- 親タスク T-0406 を完了できる状態にする。

## 確認結果

- `appendRunEventPayload()` は処理途中イベント追加時に `requestScrollMessagesToBottom()` を呼び出している。
- スクロール処理 effect が `streamEvents` の参照更新を監視するため、50件上限で件数が変わらない場合も描画後に最下部へ追従できる。
- `npm run build` は Node.js 20.18.1 / Vite 8 要件不一致で未完了。実装差分は1行で、既存の通常メッセージ追加時依存は維持している。
