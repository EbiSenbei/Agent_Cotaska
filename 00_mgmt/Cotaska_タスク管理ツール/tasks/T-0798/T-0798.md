利用者の指示により、プロジェクトのai-chatフォルダをGit管理外にする。アプリの仕様変更は伴わないリポジトリ管理設定の整理として扱う。

- [x] .gitignoreに /00_mgmt/Cotaska_タスク管理ツール/ai-chat/ を追加した。
- [x] 追跡済みimage-manifest.jsonは実ファイルを保持してGitの追跡を解除した。
- [x] git check-ignoreで画像と対応表への除外適用、git ls-filesで対象配下の追跡0件、既存2ファイルの変更前後SHA-256一致を確認した。
- [x] DECISIONS.mdへ方針と検証結果を記録した。

Gitの過去履歴は保持。起動中Cotaskaのwatcherによる完了状態のインデックス反映を確認済み。利用者の追加指示により、今回の除外設定・追跡解除・本タスク・判断記録を日本語メッセージでコミットし、origin/mainへプッシュする。ほかの作業中のソース・タスク変更と、それらが混在する生成インデックスの差分はコミット対象から除く。
