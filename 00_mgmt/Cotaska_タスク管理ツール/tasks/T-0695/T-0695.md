## 調査結果

- 添付画面は Microsoft Defender SmartScreen の「認識されないアプリ」警告。画像だけでは悪意あるファイルの検出を意味しない。
- リポジトリに残る v0.4.3 の NSIS インストーラ 20_app/release/Cotaska-0.4.3-win-x64.exe は Get-AuthenticodeSignature で NotSigned。ユーザーが実行したファイルそのものの署名状態は未確認。
- 現行 v0.4.5 の 20_app/package.json に win.signAndEditExecutable: false がある。過去の判断ログには、Windows のシンボリックリンク作成権限によるビルド問題への回避策と記録されている。単純に true へ変える前にビルド環境を検証する。
- Microsoft公式資料では、未署名ファイルは版ごとに評価を築き直し、OV/EV署名をしても新規ファイルの警告消失は保証されない。Store配布のMSIXはMicrosoftが再署名し、Store経由の導入時のSmartScreen警告を回避できる。

## 残る確認

実際に警告が出たファイルの版数、取得元、SHA-256、署名状態を記録する。現行公開版の検証は配布方針決定と並行して行う。
