T-0388 の追加要望に対する実装タスク。

## 実装内容

- AIチャットの処理途中表示で、コマンドライン詳細部分だけを折り畳み UI として表示する。
- 通常の途中経過メッセージは従来どおり累積表示する。
- 折り畳みの開閉状態が、途中経過追加時に不自然にリセットされないようにする。
- 最終回答受信時、エラー時、キャンセル時の途中経過クリア挙動を既存仕様と整合させる。

## 完了条件

- コマンドライン詳細が初期状態で折り畳まれて表示される。
- 展開操作により詳細ログを確認できる。
- 通常の途中経過は読みやすい状態で累積表示される。
- 最終回答表示時に途中経過表示が残らない。
- ビルドまたは該当範囲の検証が成功している。

## 実施結果

- `command_execution` の詳細だけを初期折り畳みで表示し、通常の途中経過は従来どおり累積表示するように実装した。
- 展開状態はイベントID単位で保持し、途中イベント追加によって展開済みの詳細が閉じないようにした。
- 最終回答、エラー、キャンセル、新規送信時には途中イベントと開閉状態を一括クリアする。

## 検証結果

- `npm run build` を実行し、Vite の本番ビルドが成功した。
