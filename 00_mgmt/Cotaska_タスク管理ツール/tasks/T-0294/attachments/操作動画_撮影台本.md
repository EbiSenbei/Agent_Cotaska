# Cotaska 操作動画の撮影台本

目標尺は45〜60秒。横長・無音のMP4を想定する。AIの処理待ちはカットし、実際の操作・応答・保存結果を使用する。

| 目安 | 画面と操作 | 伝えること |
| --- | --- | --- |
| 0〜5秒 | Cotaskaのメイン画面を表示 | 人とAIが同じタスクで作業できる |
| 5〜13秒 | 「Cotaskaの紹介文を作る」を1件追加 | 思いついた仕事をすぐ登録 |
| 13〜23秒 | 詳細に目的・完了条件を入力 | 依頼内容とゴールを残す |
| 23〜35秒 | タスクからAIチャットを開き、紹介文の作成と結果保存を依頼 | タスクをもとにAIへ依頼 |
| 35〜48秒 | 実際のAI応答と保存された紹介文を表示 | 作業の結果がファイルに残る |
| 48〜55秒 | 更新されたタスク詳細を表示 | あとから人もAIも確認できる |

## 実演する依頼内容

タスク名：Cotaskaの紹介文を作る

目的：人とAIが協力できるローカルタスク管理ツールとして、Cotaskaを短く紹介する。

完了条件：
- 80〜120文字の日本語紹介文を作成する。
- 紹介文をMarkdownファイルへ保存する。
- タスク本文に結果の保存先と実施結果を追記する。

AIへの依頼：このタスクの目的と完了条件に従い、紹介文を作成してMarkdownファイルへ保存してください。タスク本文にも保存先と実施結果を追記してください。

## 撮影・保存方針

- 実演用プロジェクトを使い、既存の業務タスクやAI履歴が映らないようにする。
- AIの結果を事前に捏造しない。処理待ちを省略した箇所には「待ち時間を短縮」と表示する。
- マイク・PC音声を収録しない。
- 保存先：この台本と同じattachmentsフォルダ。
- 最終確認：30〜60秒、文字の可読性、実際の追加・編集・AI依頼・保存結果、音声なしを確認する。
