- [x] Codexで「自動」「GPT-5.6 Terra」「GPT-5.6 sol」を選択して保存できる。

- [x] AIチャット画面にモデル選択UIがない。

利用者の完了承認により確認完了。Codexの「自動」は `自動（現在: GPT-5.6 Terra）` と表示する。
