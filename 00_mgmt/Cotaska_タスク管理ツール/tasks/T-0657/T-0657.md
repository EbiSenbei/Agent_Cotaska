## 目的

既知脆弱性を含む直接依存・開発依存を修正版へ更新し、監査結果を改善する。

## 完了条件

- 優先対象の依存とロックファイルが更新されている
- `npm audit` と `npm audit --omit=dev` の結果が記録されている
- 自動テストとビルドが成功している

## 実施結果

- `adm-zip`、`js-yaml`、`markdown-it`、Vite、Vitest、electron-builder等を修正版へ更新した。
- `npm audit fix` で許容範囲内の間接依存も更新した。
- 更新前30件（critical 1 / high 23 / moderate 6）だった全依存の監査結果は0件になった。
- 本番依存の監査結果も更新前10件から0件になった。
- Node.js 22.14.0 / npm 10.9.2で全38テストとプロダクションビルドに成功した。
