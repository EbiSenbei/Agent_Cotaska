## 発生経緯

1. CHG-122 の実装後、Portableビルドとこの環境へのリリースを実施した。
2. `release-all.ps1 -Version 0.3.6` はステップ0.5の `npm ci` で、既定npmキャッシュへのアクセス時に `EPERM` となり停止した。
3. 専用npmキャッシュを指定して再試行したところ、npmレジストリからのパッケージ取得が `EACCES` で拒否され、`npm ci` が完了しなかった。
4. 途中で終了した `npm ci` により `20_app/node_modules` の依存関係が不完全となり、`sql.js` を解決できず、`release-all.ps1` の必須依存関係検証も停止した。
5. 配布物の生成・タスクマスター配布先への同期は実行していない。

## 発生内容

`20_app/release-all.ps1 -Version 0.3.6` のステップ0.5で `npm ci` が失敗し、Portableビルドとこの環境への同期を完了できない。

## 確認済みの原因

1. 既定のnpmキャッシュではファイル操作が `EPERM` となる。
2. 専用キャッシュへ切り替えると、npmレジストリからのパッケージ取得が `EACCES` で拒否される。
3. `npm ci` の途中処理により `20_app/node_modules` の必須依存関係（`sql.js` など）が欠け、リリーススクリプトの依存関係検証も停止する。

## 対応方針

- npmレジストリ／キャッシュへアクセス可能な環境を確保し、Node.js 22.14.0・npm 10.9.2で `npm ci --no-audit --no-fund` を完走させる。
- 必須依存関係を復元後、`release-all.ps1 -Version 0.3.6` を再実行する。
- 出荷前検証が成功した場合のみ、`sync-task-master-release.ps1` を実行する。

## 完了条件

- `npm ci --no-audit --no-fund` がエラーなく完了する。
- `release-all.ps1 -Version 0.3.6` が終了コード0で完了する。
- `release/Cotaska-Portable.zip` が生成される。

## 対応・検証結果

- 権限承認付きの実行環境で、同梱 Node.js 22.14.0・npm 10.9.2 を使用した `npm ci --no-audit --no-fund` が成功し、531パッケージを復元した。
- `release-all.ps1 -Version 0.3.6` が終了コード0で完了した。
- Renderer・Electron・ランチャー・Updaterのビルドと全出荷前検証が成功した。
- `20_app/release/Cotaska-Portable.zip` を生成した（376,654,548 bytes）。
- SHA-256 は `2d33c980be3bc70bc53a1e41b6bb406ca44f2d0f8c66f9b2c402acf9292115bc` で検証済み。
- ソースコードの修正は不要。通常サンドボックスのファイル／ネットワーク制限が原因であり、リリース時は npm キャッシュとレジストリへアクセス可能な実行環境を使用する。
- バグ対応運用ルールに従い、ユーザー確認待ちとする。
