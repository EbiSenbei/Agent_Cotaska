# CHG-081-02 実装：Cloudflare R2更新メタデータ対応

## 目的

Cotaska の更新確認・ダウンロード処理が Cloudflare R2 の `latest/version.json` と配布ファイルを使えるようにする。

## 対応内容

- 既定の `latestVersionUrl` を Cloudflare R2 の `latest/version.json` に変更。
- 既定の `downloadPageUrl` を Cotaska サイトのダウンロードページに変更。
- 旧GitHub既定URLが `settings.yaml` に残っている場合は、Cloudflare R2 既定URLへ移行する。
- `version.json` の `version` と `files.portable` / `files.sha256` から zip と checksum のURLを解決できるようにした。
- GitHub Releases latest API 形式の asset 解決は互換対応として維持。

## 検証

- Cloudflare R2 形式と GitHub Releases 形式のメタデータ解決を Node.js スクリプトで確認。
- `npm run build` で renderer / main のビルド成功を確認。

## 完了条件

- [x] Cloudflare R2 の `version.json` 形式から更新情報を組み立てられる
- [x] GitHub Releases latest API 形式を引き続き読める
- [x] ビルドが成功する
