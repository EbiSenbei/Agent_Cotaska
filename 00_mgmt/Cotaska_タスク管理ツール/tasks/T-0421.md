CHG-097 に基づき、Cotaska 内の日付入力 UI の利用箇所を調査し、対象範囲と画面設計を整理する。

## 実施内容

- 日付入力コンポーネントと利用画面を洗い出す。
- テキストボックス風の表示、直接入力、カレンダー選択、クリア操作の仕様を定義する。
- 期限日・締切日・時刻指定・ショートカット操作への影響を設計書に反映する。

## 完了条件

- 対象画面と UI 仕様が設計書に反映されている。
- 実装・確認タスクへ引き継ぐ観点が整理されている。

## 設計結果

- 詳細ペインの「日付」と「期限」を対象とする。
- 日付値または「未設定」とカレンダーアイコンを含む、テキストボックス風のフィールドへ変更する。
- フィールド全体のクリックまたはキーボードフォーカスで既存の日付変更 UI を開く。
- 日付入力、カレンダー選択、クリア、ショートカット、時刻指定、保存形式は既存仕様を維持する。
- 詳細ペインの日付のみの値は `MM/DD` として表示し、進捗・日付・期限・優先度を一行に収める。
