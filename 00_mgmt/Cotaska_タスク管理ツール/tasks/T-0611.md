## 実施結果

- ダウンロードページ、トップページ、使い方ページをインストール版の案内へ更新した。
- GitHub latest APIから最新版タグとWindows x64インストーラーAssetを取得し、ダウンロードボタンへ直接URLを設定するようにした。
- API取得失敗時はGitHubの最新Releaseページを開くフォールバックを維持した。
- JavaScript構文検査に成功し、GitHub APIの実データでv0.4.0インストーラーを検出できることを確認した。
- サイト内にCloudflare R2、Portable ZIP、ポータブル版の現行案内が残っていないことを確認した。
- `efa192d CHG-128 ダウンロード先をGitHub Releasesへ変更`として`cotaska-site`の`main`へコミット・プッシュした。
- GitHub Pagesのビルド完了後、公開ページとJavaScriptがHTTP 200で、新しいGitHub Releasesリンク／latest APIを配信していることを確認した。
