クイック入力を実装し、`Ctrl+K`、IME変換中でないEnter、登録ボタンによる作成を既存のタスク作成処理へ接続する。作成成功時は返却された新規タスクIDで既存の詳細表示処理を呼び出す。

保存中は登録操作を無効化し、失敗時は入力内容を保持してエラーを表示する。既存の通常入力・入力補正・タスク一覧更新を壊さない。

## 完了条件

- [ ] 自動テストまたは同等の回帰検証を追加・実行している。
- [ ] `Ctrl+K`、IME中Enter、成功時詳細表示、失敗時入力保持、連打防止を確認している。
- [ ] Node.js 22系で本番ビルドを実行している。

## 実施結果

- `Ctrl+K` / `Cmd+K` による入力欄フォーカス、Enter・登録ボタンによる登録、保存中の二重登録防止、失敗時の入力保持とエラー表示を実装した。
- `明日 企画書レビュー #仕事 !高` の形式から、期限・タグ・優先度を抽出して保存し、作成成功時は返却されたタスクIDで既存の詳細ウィンドウを開くようにした。
- Vite 8のESM設定として `vite.config.mjs` を追加し、開発・ビルド・テストスクリプトを更新した。
- Node.js v22.14.0 / npm 10.9.2で `npm test`（9件成功）および `npm run build`（113モジュール変換成功）を確認した。
