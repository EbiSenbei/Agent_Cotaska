# 新規Windows環境での導入確認手順

対象：T-0295の残項目「初見ユーザーが公式サイトから入手し、初回起動後に最初のタスクを登録できる」。
利用者から別のWindows環境で確認できるとの回答と、2026-10-26に公式サイト経由のダウンロード・インストール成功報告を受領した。初回タスク登録は未実施だが、利用者の動作の受入判断は「確認済み扱い」。実測項目の記録と受入判断を下記の記録欄で区別し、追加操作は依頼しない。

## 準備と今回確認済みの範囲

- Windows 10 / 11 x64の別PC、またはCotaska未導入のWindows仮想環境を使用する。
- このPCはCotaska運用中で、WindowsSandbox.exeを確認できず、この機能は使用していない。同じPCへの上書き導入は新規環境の確認とは区別する。
- インストーラーは通常配布の共通インストール版。現在のビルド設定は `perMachine: true` で、実行すると既存インストールやスタートメニューに影響するため、今回このPCへのインストールは行っていない。
- 動作中のCotaskaは起動時に共通スタートメニューの `Programs/Cotaska/Cotaska.lnk` を更新する実装であるため、単に別の製品EXEを起動する方法も既存設定を保護する確認の代替としては採用していない。
- 検証時点の公開版：v0.5.1、`Cotaska-0.5.1-win-x64.exe`。公式サイトのボタンから実際のファイル取得が完了した。
- このPCでの取得先：`C:/Users/EBI-GALLERIA/Downloads/Cotaska-0.5.1-win-x64.exe`。
- サイズ：371,791,788 bytes。
- SHA-256：`4a8bb42155a09824193cc3f9532be256ff49a355ed05ceba9dc5c10d700348ed`（公開値と一致）。詳細は [取得記録](download-validation.json)。
- 本体のタスク管理はAI認証なしで確認する。AIの契約・認証や実サービスへの送信はこの確認に含めない。

## 操作と合格条件

| 段階 | 操作 | 合格条件・記録 |
| --- | --- | --- |
| 1. 入口 | 公式サイトを開く。公開前の確認ならローカル修正サイトを検証端末から閲覧できる方法を別途決める | 紹介、OS・料金、動画、ダウンロードが分かる |
| 2. 入手 | ダウンロードページから最新版EXEを取得。実施時点のリリース・ファイル名・ハッシュを照合 | インストーラーが取得でき、同版の公開値と一致する |
| 3. 導入 | 利用者がインストール実行を許可した環境でEXEを実行し、案内に従う | 正常終了。スタートメニューからCotaskaを起動できる。警告やUACは表示内容と判断を記録する |
| 4. 初回起動 | 「プロジェクトを選択」画面で「新しいプロジェクトを作成」。専用の書き込み可能な空フォルダを指定 | `project.yaml`・`tasks/`などが作成され、タスク一覧へ進む |
| 5. 1件登録 | 「すべて」を開き、クイック追加欄へ「最初のタスクを登録する」と入力してEnter | 一覧に1件追加される。日付未設定でも「すべて」で確認できる |
| 6. 詳細入力 | タスクを選び、「メモを入力...」欄へ目的・完了条件を書く。プレビュー表示中なら「編集モードへ切替」を選ぶ | 本文を編集でき、自動保存される。入力後は少し待ってから別タスクへ移る |
| 7. ファイル | 指定したプロジェクトの `tasks/T-0001/T-0001.md` を確認（既存IDがあれば実際のID） | 入力したタイトルと本文をMarkdownとして確認できる |
| 8. 再起動 | Cotaskaを終了して再起動し、作成したプロジェクトを開く | タスクと本文が保持される。AIの設定をしなくてもここまで進められる |
| 9. 問い合わせ | サイトからサポート・更新履歴へ移動する | 正しいGitHub IssuesとReleasesへ到達する。投稿はしない |
