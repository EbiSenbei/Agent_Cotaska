# CotaskaのSNS選定案（2026-10-26）

## 推奨

**日々の発信と反応収集はXを主軸とし、YouTubeは既存の紹介動画を掲載する補助媒体として使う。**
noteで詳しい説明を用意する方針は維持する。最初からすべての媒体を継続運用せず、note → Xで初回発信 → YouTubeに既存動画を1本掲載する順で始める案。YouTubeの定期投稿、Shortsや縦型動画の新規制作は初回発信の必須条件にしない。

これは利用者へ提示する推奨案であり、採用・アカウント・公開先は未決定。アカウント開設・投稿・動画アップロードは行っていない。

## 判断の前提

- 最初の想定ユーザーはAIエージェントと開発する個人開発者（T-0292）。
- 共通メッセージは「タスク管理とAIチャットを、ひとつの作業画面に。」。
- 公式サイトと通常インストーラーの配布導線は公開済み。
- 採用済み紹介動画は横長1920×1080、60秒、約5MB。画像・サムネイル・SRT字幕も用意済み。
- note・SNS・Boothは未使用。既存フォロワーやチャンネルがあるという前提は置かない。

媒体の優先順位は、Cotaskaの現状と作業量に基づく判断。各媒体の規模や、開設後に得られる流入数を測定した結果ではない。

## 媒体の比較

| 媒体 | Cotaskaでの役割 | 初期の使い方・判断 |
| --- | --- | --- |
| X | 開発の進捗・具体的な利用例の発信、質問や感想への応答 | 主軸候補。短文と画像で機能を一つずつ紹介し、60秒動画はXへ直接添付する。公式サイトをプロフィールと固定投稿に置く |
| YouTubeの通常動画 | まとまった紹介・操作説明を掲載し、記事や他の投稿から参照する | 補助として推奨。既存の横長60秒動画を1本掲載するところから始める。新しい編集や定期投稿は初期要件にしない |
| YouTube Shorts | モバイル向けの短い実演を別途試す | 後から検討。既存動画は横長なので、そのままShortsとして使う計画にはしない。文字の多いPC画面は縦型への再構成を検討する |
| Bluesky | X以外の反応を比較する追加候補 | 初期は増やさない。Xの発信が回るようになり、利用者からの反応や運用上の理由があれば検討する |
| Zenn・Qiita | AIとMarkdownタスクを共有する仕組みや、開発で得た技術的な知見を伝える | 商品紹介記事の複製先にはしない。読者が再利用できる技術記事を別に書ける段階で検討する |
| Instagram・TikTok | 縦型の実演を試す候補 | 初期は優先しない。今回のPC向け横長素材を使い切ることを先に進め、縦型制作の負担を増やさない |

## Xで発信する内容

T-0821の既存5テーマをそのまま活用する。

1. 問題提起：AIへの依頼とタスク管理が分かれていると、どこまで進んだかを追いにくい。
2. 画面紹介：複数タスク・子タスク・遅延／今日／完了の整理。
3. 60秒動画：タスク管理とAIチャットを同じ画面でつなぐ流れ。
4. 導入案内：公式サイトからインストールし、最初のタスクを作る。
5. 開発背景：ローカルのMarkdownを正本にしている理由など、確認済みの事実を使う。

動画投稿は外部YouTubeリンクだけにせず、既存のMP4を直接添付する案。投稿内で内容が分かるようにし、入手先は公式サイトへ案内する。表示回数だけで評価せず、T-0298の公式サイト訪問・入手アクション・有効反応で見直す。媒体別の値を取得できない場合は推定値で補わない。

## YouTubeで最初に用意するもの

- 既存の60秒動画を通常の横長動画として1本掲載する。
- タイトル案：`Cotaska紹介｜タスク管理とAIチャットを、ひとつの作業画面に。`
- 説明欄：製品の短い説明、公式サイト、Windows x64、本体無料・AI連携先の利用条件は別途という案内、音声クレジット。
- サムネイルと日本語字幕はT-0294の完成素材を再利用する。
- チャンネルのプロフィールリンクから公式サイトへ案内する。説明欄の外部リンクを含め、実際の利用資格と公開画面で遷移を確認する。
- 主目的は説明動画の掲載と再利用。1本置くだけで検索流入が得られるという前提にはしない。

noteへYouTubeを埋め込む場合は実URLの取得後に表示を確認する。当面の公式サイト上の動画はすでに公開できているため、YouTube準備をnote・Xの公開を止める条件にしない。

## 調べた仕様と参照先

- Xの通常枠でも動画は140秒・512MBまで。既存動画の60秒・約5MBはこの時間・容量の枠内。投稿前に実ファイルの受理と表示も確認する。[X公式ヘルプ](https://help.x.com/ja/using-x/x-videos)
- YouTube Shortsは正方形または縦長・3分以内の動画が対象。長さが60秒であるだけではShortsにはならない。既存の16:9動画は通常動画として使う。[YouTube公式ヘルプ](https://support.google.com/youtube/answer/15424877?hl=ja)
- Shortsの説明・コメントのURLはクリックできない。Shortsを採用する場合の誘導先はプロフィールリンクなどを使って別途設計する。[YouTubeのリンクに関する公式説明](https://support.google.com/youtube/answer/13748639?hl=ja)
- Blueskyも動画に対応しているが、現時点では追加運用の必要性を先に判断する。古い開始時点の60秒制限だけを根拠に比較しない。[Bluesky公式・2026年の方針](https://bsky.social/about/blog/01-26-2026-whats-next-at-bluesky)
- Zenn・Qiitaは技術的な知見共有を重視し、宣伝を主目的とする記事には制約がある。[Zennガイドライン](https://zenn.dev/guideline)、[Qiitaガイドライン](https://help.qiita.com/ja/articles/qiita-community-guideline)
