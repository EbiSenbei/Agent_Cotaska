# CHG-081-03 ユーザー確認：Cloudflare更新確認・ダウンロード確認

## 目的

Portable版で Cloudflare R2 を使った更新確認と更新ファイルのダウンロードが期待どおり動作することを確認する。

## 確認観点

- 設定画面の「更新を確認」で Cloudflare R2 の `latest/version.json` を取得できる。
- 最新版がある場合、更新あり状態とバージョン番号が表示される。
- 「更新をダウンロード」で Cloudflare R2 の `Cotaska-Portable.zip` を取得できる。
- `.sha256` が取得できる場合、SHA-256検証後に再起動更新可能な状態になる。

## 完了条件

- [ ] ユーザーが Cloudflare R2 経由の更新確認を確認する
- [ ] ユーザーが Cloudflare R2 経由のダウンロードを確認する
