タスクを完了したり、タスク詳細を記載した後に、
メインパネルのタスクリストが一瞬白くなってちらちらする。
または、タスク完了した後に一瞬操作できなくなる瞬間がある
原因調査からしてほしい

## 起票

- バグID: BUG-20260625-01
- バグレポート: `Cotaska/10_docs/30_変更管理/20_バグレポート/20260625_01_タスク更新時に画面がちらつく.md`

## 対応結果

- `20_app/src/renderer/App.jsx` で初回ロードと通常更新ロードを分離。
- 通常更新時は `loading` を立てず、既存タスクリストを空表示にしないよう修正。
- watcher の `tasks:changed` payload を利用し、更新通知時の追加 `tasks:getAll` を抑制。
- 同梱 Node.js 22.14.0 で `npm.cmd run build` 成功。
