既定のNode.js 20.18.1がVite 8の要件を満たさず、ビルド検証が繰り返し失敗していたため、Cotaskaの開発ランタイムをNode.js 22.14.0／npm 10.9.2に明示的に統一した。

- `20_app/.nvmrc`、`package.json`の`engines`と`packageManager`に推奨版を記録。
- `npm run dev`と`npm run build`の前にランタイム検査を実行。
- Node.js 20.18.1では切替案内付きで停止し、Node.js 22.14.0／npm 10.9.2では本番ビルド成功を確認。
