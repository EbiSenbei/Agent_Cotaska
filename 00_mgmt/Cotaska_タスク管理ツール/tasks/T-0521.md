Cotaska.exeより毎回以下のエラーが表示されます。
CotaskaCoreは動いてます。
# エラー
Cotaska を起動できませんでした。

検出内容:
CotaskaCore.exe が起動後 10 秒以内に終了しました。終了コード: 0
最新の debug.log エラー: debug.log はありません。

利用可能な更新前バックアップ:
D:\Development\Git\EbiSenbei_dev\Agent_Cotaska\Cotaska\00_mgmt\Cotaska_タスク管理ツール\backup\portable-update-before-20260719_225406.zip

自動復元は _app のみを置き換えます。data/、logs/、backup/ は変更しません。

## 調査記録

- BUG-20260720-01 を起票。
- 既存の CotaskaCore が single-instance lock により二重起動プロセスを終了コード 0 で終了していることを確認。
- ランチャーが終了コード 0 の早期終了を無条件で起動失敗として扱うため、誤って復旧ダイアログを表示していると判断。
- `LauncherFallback.cs` を修正し、同一 Portable ルートの既存 CotaskaCore を検出した終了コード 0 は正常な二重起動として扱うように変更。
- ランチャーを再ビルドしてタスク管理ツール環境へ反映。二重起動テストでランチャー終了コード 0 と正常終了ログを確認。
