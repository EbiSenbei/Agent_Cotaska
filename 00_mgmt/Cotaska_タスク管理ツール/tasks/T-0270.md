画面左に「明日」のフィルターがあるが、
明日(今日5/27なら5/28)のタスクが表示されない不具合がある。

https://www.youtube.com/

## 対応メモ

- バグレポート: `10_docs/30_変更管理/20_バグレポート/20260527_01_明日のタスクが表示されない.md`
- 原因: 「明日」ビューの通常タスクは `visibleTasks` に入っていたが、空の `progressSections` が描画側で優先され、通常タスクのフラット表示が呼ばれていなかった。
- 対応: 「明日」ビューでも日付セクション `📅 明日` を渡し、進捗セクションが空の場合は `null` として扱うよう修正。
- 検証: Node.js で修正対象ロジックを再現し、2026-05-27 時点の 2026-05-28 期限タスクが明日セクションへ入ることを確認。
- 制限: `npm run build` は Node.js 20.18.1 と Vite 要件 20.19+ の不一致、および `vite.config.js` の ESM 読み込みエラーで未完了。
