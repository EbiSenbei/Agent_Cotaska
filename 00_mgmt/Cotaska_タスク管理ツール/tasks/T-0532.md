利用者がクイック入力でタスクを登録し、登録直後にそのタスク詳細が開くことを確認する。

## 確認項目

- [x] `Ctrl+K` で入力開始できる。
- [x] 日本語IME変換中のEnterで登録されない。
- [x] Enterと登録ボタンの双方で、作成したタスクを右側の詳細パネルで表示する。
- [x] 登録失敗時に入力内容が残り、詳細が開かない。
- [x] この挙動を日常利用で採用することを確認した。
