## 作業内容

Codex SDKを使ったAIチャット連携の設計を既存設計資料へ反映する。

CHG-058の対象はCodex SDKのみとし、GitHub Copilot CLI / Claude Code / Gemini CLI などの複数AI CLIプロバイダ追加は対象外とする。

## 反映観点

- CotaskaからCodex SDKを呼び出す責務分担
- Codex SDKのみを連携対象とし、複数AI CLIプロバイダ方式を採用しない方針
- renderer/main/preload間のIPC設計
- Codex SDKの作業フォルダ、参照ファイル上限、認証状態確認の扱い
- 認証情報をCotaskaに保存しない方針
- AIスレッド、チャット履歴、Codex SDK側threadId、参照ファイル、実行ログ、承認履歴をSQLite（data/ai.sqlite）へ保存する方針
- AI画面構成（サイドバー、AIスレッド/ファイル切り替え、チャット、右プレビュー）
- AI応答をタスク更新へ反映する際の承認制ルール
- 許可アクション update_task / create_task / update_file と、不正な構造化アクションを拒否する検証方針
