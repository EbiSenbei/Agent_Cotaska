T-0385 の後続仕様変更として、AIチャット上の Markdown リンクを添付ファイルクリック時と同じ右サイドパネル表示にする設計タスク。

## 目的

- AIチャット本文のローカルファイルリンククリック時に、外部アプリ起動ではなく Cotaska 内の右サイドパネル表示へ誘導する。
- タスクファイルはタスク詳細、通常ファイルはテキスト/PDF/Markdownプレビューとして開く仕様を整理する。
- 白画面化防止のメインウィンドウ遷移ガードは維持する。

## 設計内容

- `AiChatPane` の Markdown リンククリック処理を、添付ファイルクリック時の `openFileContext` と同じ表示経路へ接続する方針を決める。
- `http://` / `https://` は従来どおり外部ブラウザで開く。
- ローカルファイルリンクは main process 側で安全に解決し、renderer は解決済みパスを右サイドパネル表示に渡す。
- `file://`、相対パス、URLエンコード、行番号付きリンクの扱いを明記する。

## 完了条件

- CHG-092 の仕様変更管理ファイルに設計方針が反映されている。
- AI連携設計書の更新要否を確認し、必要な追記内容が整理されている。
- 実装タスクで扱う IPC / renderer の変更範囲が明確になっている。

## 実施結果

- CHG-092 と AI連携設計へ、ローカルリンクを main process で解決して既存右サイドパネルへ表示する方針を反映した。
- `file://`、相対パス、URLエンコード、行番号サフィックスの正規化基準と、外部URL・エラー時の扱いを整理した。
