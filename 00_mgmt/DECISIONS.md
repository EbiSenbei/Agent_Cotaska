## 2026-06-03 BUG-20260603-01 更新確認 fetch failed 対応方針

- 更新確認で Node `fetch` が `ECONNRESET` となる環境差（Windows通信スタックでは成功）を確認したため、`checkForUpdates` の更新メタデータ取得は Node `fetch` 失敗時に `electron.net` へフォールバックする。
- 失敗時ログは `error` だけでなく `url` / `code` / `cause` を記録し、社内ネットワーク制限・TLS 切断の切り分けを容易にする。
- 利用者向けメッセージは `fetch failed` をそのまま表示せず、`ECONNRESET` / `ENOTFOUND` / `ETIMEDOUT` を日本語で説明し、確認対象URLを併記する。

## 2026-05-15 Cotaska 起動時の画面表示高速化

- 起動時にタスク/リストサービス初期化、全タスク読み込み、`_index.yaml` 再生成を完了してから `BrowserWindow` を作る構成は、画面表示までの体感時間をI/O量に依存させるため見直した。
- `BrowserWindow` はデータディレクトリ確保と必要な開発サーバ準備後に先行作成し、サービス初期化は `servicesReady` Promise として起動後に進める。
- IPC ハンドラは引き続き `servicesReady` を await するため、画面は早く出しつつ、タスク/リスト操作は初期化完了後に実行する方針とした。
- ファイル監視とリマインダーはタスクキャッシュ準備後に開始し、未初期化状態の検索ルートや空キャッシュを参照しないようにした。
- `_index.yaml` 再生成は既存内容との差分がない場合に書き込みを省略し、クラウド同期フォルダ配下での起動時I/Oを増やさない方針とした。

## 2026-05-05 BUG-20260505-03 タスクマネージャ表示名

- タスクマネージャ上の `Electron` 表示はアイコンではなく、`CotaskaCore.exe` の `FileDescription` / `ProductName` などのバージョン情報が Electron 由来のまま残っていることを主因候補とする。

## 2026-05-05 BUG-20260505-02 親子進捗連動と保留の優先

- 親タスクの進捗自動推定は、親タスクが `未着` の場合だけ実行する。
- 親タスクを `保留` にした場合は未完了の `未着` / `仕掛` 子孫タスクを `保留` へ同期し、完了済み子孫タスクは変更しない。

## 2026-06-25 CHG-088 ドラッグ親子紐づけ

- T-0026 の要望を CHG-088 として起票し、既存タスクをドラッグ操作で別タスクの子にできる仕様として具体化する。
- 保存先は既存 frontmatter の `parent` を使い、新規スキーマ追加は原則行わない。
- 通常の並び替えと親子紐づけを誤認しないよう、ドロップ位置・視覚フィードバック・禁止条件・解除導線を設計段階で固める。
- 実装では、行中央ドロップを子タスク化、行上下ドロップを並び替えとし、親子解除はドラッグ中の「親なしに戻す」領域で行う。

- 追加方針として、子タスクの行上下ドロップは親子関係を維持せず、ドロップ先タスクと同じ親階層へ付け替えて並び替える。
- ドラッグ操作はネイティブHTML5ドラッグとポインター方式を混在させず、Electron上で挙動が安定したポインター方式へ寄せる。
- ドラッグ開始時にリストの表示位置が変わるとドロップ先がずれるため、「親なしに戻す」領域は非表示時もスペースを確保し、ドラッグ中のレイアウト変化を避ける。
- 2026-06-27 追加整理として、「親なしに戻す」専用領域を主導線にせず、行中央は子タスク化、行上部/下部はドロップ先と同じ親階層への移動として扱う。親なしタスクの上下へドロップした場合は `parent: null` へ戻す。
- BUG-20260627-01 対応として、独自ポインター方式と「親なしに戻す」専用領域は撤去し、メイン一覧の標準順表示だけを対象に HTML5 Drag & Drop へ一本化する。親子変更と並び替えは `reorder` の `field_updates` で `parent` / `list` も含めて一括保存する。
- BUG-20260627-02 対応として、子タスクの `保留` は親タスクへ自動伝播しない。子タスク由来の親タスク再推定は `仕掛` / `完了` の子がある場合の `仕掛` 自動開始に限定し、親タスクを明示的に保留へ変更した場合の子孫同期は維持する。

## 2026-07-15 CHG-105 ランチャー起動診断と確認付き自動復元

- `Cotaska.exe` は通常起動を維持しつつ、`_app` の必須ファイル不足または本体の起動直後の異常終了時だけ、エラー内容・バックアップ候補・ログ参照導線を持つ復旧ダイアログを表示する。
- 自動復元の対象はアプリ本体の `_app` に限定し、利用者データの `data/`、履歴の `logs/`、保存済みバックアップの `backup/` を変更しない。実行前には対象ZIPと実行中プロセスを明示して確認を得る。

## 2026-07-15 CHG-106 CotaskaUpdaterの更新中ダイアログ表示

- 更新処理中の利用者通知は、Cotaska本体ではなく独立して動く `CotaskaUpdater.exe` のWindows Formsダイアログで行う。更新段階は不確定進捗バーと状態メッセージで表示し、処理件数・所要時間に依存する百分率は表示しない。
- 更新中は利用者がダイアログを閉じられないようにし、成功時は再起動後に自動で閉じる。失敗時は状態ウィンドウを閉じて既存のエラーダイアログと更新ログへ誘導する。

## 2026-07-15 CHG-107 AIチャット返信時のWindows通知

- AIモードの最終返信は、対象AIスレッドがrendererで選択・表示中でない場合だけWindows通知を表示する。途中イベント、エラー、キャンセルは対象にしない。
- Cotaska側の通知設定は追加せず、Windowsの通知許可・集中モードに従う。通知クリック時はCotaskaを前面化し、該当AIスレッドを開く。
- mainプロセスで実行IDごとに重複を抑止し、rendererとは `aiChat:setActiveThread` と `aiChat:openThread` のIPCでアクティブ状態・クリック遷移を連携する。通知機能の失敗はAI返信処理へ伝播させない。

## 2026-07-15 CHG-108 AIチャット入力履歴の呼び出し

- 入力履歴はAI応答を含めず、選択中AIスレッドのユーザー送信メッセージだけを対象とする。
- 空欄時の `ArrowUp` は最新投稿から古い順、履歴呼び出し中の `ArrowDown` は新しい順に移動し、最新の次で空欄へ戻す。
- 履歴はrendererの表示済みメッセージから導出する一時状態とし、DBスキーマ、IPC、永続設定を追加しない。手入力を始めたら履歴移動状態を解除する。

## 2026-07-16 CHG-109 AIチャット内フォルダリンク

- AIチャットのMarkdownローカルリンクは、ファイルとフォルダをmain processで存在確認して判別する。ファイルは従来どおり右プレビューへ、フォルダは既存の `shell:openPath` を通じてOSのエクスプローラーで開く。
- rendererから直接Node/Electron APIへアクセスせず、context isolationを維持するため、既存preload bridgeの `window.cotaskaAPI.shell.openPath` を使用する。DBスキーマ・永続設定・IPCチャンネルは追加しない。

## 2026-07-16 CHG-110 AIチャット自動スクロール制御

- AIチャットのストリームイベント受信時は、メッセージ一覧が最下部から96px以内の場合だけ自動スクロールする。過去メッセージを閲覧・選択中に位置を移動させないためである。
- 96pxは既存の「最下部へスクロール」ボタンの表示閾値と共通化し、利用者に見える状態と自動追従の判定を一致させる。DBスキーマ、IPC、永続設定は変更しない。

## 2026-07-17 CHG-114 AIチャット未読ランプ表示

- 未読状態はタスクMarkdownではなく、AIスレッドの既存永続ストア `ai.sqlite` の `ai_threads` に保持する。バックアップ対象を増やさず、再起動後も状態を復元できる。
- 既読化は `aiChat:setActiveThread` と同一のmain-process境界で実行する。通知対象のアクティブスレッドと永続状態を同じスレッドIDで更新し、選択操作とAI応答完了の競合を抑える。

- AIの最終応答が正常完了した時点で対象スレッドが非アクティブなら未読とし、一覧行右端に青色の円形ランプを表示する。対象スレッドを選択してアクティブにした時点で既読化する。
- 未読状態は再起動後も維持する。処理中はCHG-094の処理中アイコンを優先し、正常完了後に未読ランプへ切り替える。エラーと中断は未読対象外とする。
